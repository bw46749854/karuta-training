### 1.2 試し方

```bash
pnpm install --frozen-lockfile
```

```bash
pnpm --filter @karuta/web dev
```

表示されたアドレス（例：<http://localhost:5173/>）を開く。見るとよい操作：

- **設定画面**（トップ →「設定」）
  - 初めて開くと、札の配置（6段×11列）が各陣25マスで、中央に通路がある（B-27）。
  - 「決まり字を限定する」を外して「保存」→「トップへ戻る」→ もう一度「設定」で、外れたまま（B-17）。
  - グループの「あさ」を押すと、あさじ・あさぼらけあ・あさぼらけうが選ばれ、「あさ」「あさぼ」が選んだ表示になる。あさじを外すと「あさ」だけ戻る。
  - 札流しの「待機時間」に 0 や 1.5 を入れると、範囲が出て「保存」が押せなくなる。
  - 「盤面の形」を 4段×9列にして、マスを変えてから 6段×11列に戻しても、ほかの形は変わらない。
  - 変えてから「初期値に戻す」→ 保存せずに「トップへ戻る」→ もう一度開くと、前に保存した値のまま。
- **札流し**（設定で歌を数首だけ選び、出題枚数を小さくして保存してから、トップ →「札流し」）
  - 決まり字を入れて Enter。正解なら「正解」。カタカナで答えると、正解の決まり字と「ひらがなかローマ字で入力してください。」が出る（B-22）。
  - 空欄では「答える」が押せず、Enter でも何も起きない（B-25）。
  - 「スキップ」を続けると進捗が進み、「お疲れさまでした。全問終了です。」で終わる。終わった後は「スキップ」が出ない（B-24）。
  - 「うら」「うか」の2首で、決まり字変化を考慮する ON なら2問目の正解は「う」、OFF なら静的決まり字（B-01）。「うか」だけなら「うか」が正解（B-02）。
  - 「決まり字一覧を開く」で、状態（未読・初期、正解・変化、スキップ・初期 など）と、出題順の並びを見る。
  - 設定で札の向きを「逆さま」にすると、札が上下逆に出る。
- **札流し（複数枚）**（設定の「札流し（複数枚）」で同時枚数・出現時間を決めて保存してから、トップ →「札流し（複数枚）」）
  - 札が位置の順（1枚目が下段右）に出て、出現時間の後に白紙の札になる。答えると表に戻る。
  - 「む す」「mu,su」のように、1行に区切って答える。区切りだけや、札より多い答えは、知らせて入力欄を空にする。
  - 一覧で、札ごとの正誤（問が不正解でも、答えた札は正解）とスキップを見る。
- **配置暗記**（横向きの画面で、トップ →「配置暗記」。設定で歌を数首だけ選ぶと見やすい）
  - 画面の大きさに合わせて盤面の形が決まる（PC なら 6段×11列、スマートフォン横なら 4段×11列）。相手陣の札は逆さま。
  - 札・個別の一覧・グループの一覧で裏返し、「表と裏を入れ替える」「配り直す」を試す。
  - 「出題を始める」で札が裏になる。問の札があると思うマスを押して選び（白い札になる）、「答える」。
  - 設定の「回答後に正解札を表示」と「回答後に札の確認を許可」を変えると、答えた後の動きが別々に変わる（B-11）。
  - 途中で縦向きにすると案内が出て、横向きに戻すと続きから。

チェックは `pnpm verify`（CI と同じ）。

## 3. 自分で決めたこと

指示書 §4 の範囲。設計方針 §1 の優先順位（ルールの正しさ → 変更容易性 → テスト容易性 → 移植性 → 性能）で決めた。

| 論点 | 選んだもの | 理由 | 変えるときの手間 |
|---|---|---|---|
| 設定画面を定義から自動で作るか（ADR-0003 論点 D） | ON/OFF・整数・選択肢の入力欄は、定義の項目を順にたどって作る。歌の選び方と札の配置は専用の部品 | 項目の出し忘れが構造の上で起きず、画面の部品も少ない。画面の並びが定義の並び（取扱説明書 §6.1）と同じで済み、定義に画面の都合を持たせずに済んだ。項目を隠す（自動で次へが OFF のときの待機時間）ことはしない | 手で並べる形に戻すなら、`ui` の入力欄を並べている所だけ（ADR-0003 論点 D のとおり） |
| 項目の名前の文言の引き方 | 定義の型から「まとまり.項目」の名前と、選択肢の値の一覧の型を作り、文言の表はそのすべてを持つ（抜けも余分も型の誤り）。画面は、定義をたどって得た名前で表を引く | ADR-0005 §2（抜けは型の誤りにする）に合わせた。抜けた項目と余分な選択肢が型の誤りになることを、わざと壊して確かめた。画面に入力欄があることは、コンポーネントテストで確かめる | ― |
| 整数の入力 | 半角の数字だけを受け付ける。受け付けない入力は打ったまま残し、範囲を出し、保存を押せなくする。初期値に戻すと消える | 入力を甘くしない（空白・全角・小数を受け付けない）。画面に出ている値と保存される値が食い違わないよう、受け付けない入力があるうちは保存させない | 受け付ける形を変えるのは `editField` の1か所 |
| 初期値に戻す・保存せずに離れるときに確かめるか | どちらも確かめない | 初期値に戻しても保存はされず、離れれば捨てられるだけで、保存済みの値は失われない。離れるときに捨てるのは取扱説明書 §6.4 の決定 | 確かめる画面を足すだけ（§5 の提案） |
| 保存の結果のメッセージ | 「保存しました。」「保存できませんでした。」。その後に項目を変えると消す | 今の下書きが保存されているかを取り違えないため（ADR-0006 §3） | 文言の表と、画面の1か所 |
| 画面の切り替え | アドレスの「#」の後ろの名前（`#/settings`、`#/card-flow`）。新しい依存はない | ブラウザの「戻る」が使え（サンプルの利用者が使っていた）、E2E で画面を直接開ける | `apps/web/src/main.tsx` の1か所 |
| トップ画面 | できている画面のボタンだけ（札流し、設定） | 押しても何もないボタンを出さない | 画面を作るたびに1つ足す |
| 設定の初期値（仮） | 取扱説明書の各表の「設定画面の初期値」。複数枚の決まり字変化は「標準 OFF」 | 根拠のある値がこれだけ。段階 5 で調整する | 定義の1か所 |

## 5. 提案（仕様に入れていないもの）

- 設定画面に、選んでいる歌の数（例：「選んだ歌：3首」）を出す。限定が効いているかを、一覧を見なくても分かる。
- 札の配置の編集に、各陣の使うマスの数を出す（例：「相手陣 25・自陣 25」）。
- 保存していない変更があるまま設定画面を離れるときに、確かめる。今は、取扱説明書 §6.4 のとおり黙って捨てる。
- 札流しの決まり字一覧で、終わった札には、出た時点の決まり字（正解の決まり字）も出す。変化を追う練習の振り返りになる。
- 札流し（複数枚）で、判定の後に、問の札ごとの正誤や正解の決まり字を、札の近くに出す（今は一覧だけ）。
- 配置暗記で、出題の回が終わったときに、結果（正解・誤答・スキップの数や、間違えた問）を出す（仕様 07 §11）。
