# 仕様 04: 設定画面と、入口のトップ画面

- 状態：承認待ち（実装済み）
- 日付：2026-11-05（クラウドセッション。[指示書](../records/cloud-session-brief.md) §3 により、承認の前に実装した）

設定画面（全項目）と、各画面への入口として最小限のトップ画面を定める。トップ画面の残り（報告・共有、リンク集へのボタンなど）は、全体計画 段階 4 の 6 番目の仕様で決める。

根拠：

- 取扱説明書 §1.1（決まり字を限定する）、§2.3・§3.3・§4.3・§5.3（各モードの設定の表）、§6（設定画面）、§7.1（トップ画面）、§8.1（決まったこと）
- 不具合 B-17・B-26・B-27 の本来の動き
- [ADR-0003](../adr/0003-settings.md)（設定値の管理）、[ADR-0005](../adr/0005-wording.md)（文言）、[ADR-0006](../adr/0006-what-screens-show.md)（表示する情報）、[ADR-0007](../adr/0007-devices-and-screen-sizes.md)（盤面の形）
- [仕様 03](03-questions-and-dealing.md) §6.1（形ごとの初期の配置）

## 1. 用語

| 用語 | 意味 | コード上の名前 |
|---|---|---|
| 項目 | 設定の1つ。種類は ON/OFF、範囲のある整数、選択肢、歌の集まり、札の配置（ADR-0003 §1） | `Item` |
| 下書き | 設定画面で変えている途中の値 | `draft` |
| 保存済みの値 | 最後に保存した値。一度も保存していなければ初期値 | `saved` |
| 受け付けない入力 | 範囲のある整数の欄に打った、整数として受け付けない文字（§7） | `invalid` |

## 2. トップ画面（入口）

1. 見出しは「競技かるた トレーニング」（取扱説明書 §7.1）。
2. できている画面へのボタンだけを並べる。今は「札流し」「札流し（複数枚）」「配置暗記」「設定」。ほかの画面のボタンは、その画面を作るときに足す。実践練習へは、トップ画面からではなく、配置暗記から入る（取扱説明書 §7.1）。
3. トップ画面には「トップへ戻る」ボタンを出さない。

## 3. 画面の行き来

1. トップ画面のほかの、どの画面にも「トップへ戻る」ボタンを出す（取扱説明書 §7.1、§8.1）。
2. 画面ごとに、アドレスの「#」の後ろに名前を持つ（設定は `#/settings`、札流しは `#/card-flow`、札流し（複数枚）は `#/multiple`、配置暗記は `#/placement`）。ブラウザの「戻る」でも、前の画面に戻れる。再読み込みすると、その画面を初めから開く。
3. 知らない名前のときは、トップ画面を開く。

## 4. 設定画面の作り

1. 見出しは「設定」。上に「保存」「初期値に戻す」のボタンと、保存の結果のメッセージを置く。
2. 項目は、次の順に、まとまりごとに並べる（取扱説明書 §6.1 の順）。まとまりには見出しを付ける。
   1. 出題の範囲（決まり字を限定する、歌の選び方。§6）
   2. 札流し
   3. 札流し（複数枚）
   4. 配置暗記
   5. 実践練習
   6. 札の配置（§8）
3. 項目が多いので、縦にスクロールしてよい（ADR-0007 §7）。
4. ON/OFF、範囲のある整数、選択肢の項目の入力欄は、設定の定義から作る（§10）。ON/OFF はチェック欄、範囲のある整数は数の入力欄、選択肢は選ぶ欄にする。
5. どの項目も、いつも出す。ほかの項目の値によって隠さない（例：「回答後に自動で次へ進む」が OFF でも、待機時間を出す）。
6. 「デバッグ用 札の配置設定の配列」は出さない（ADR-0006 §6）。

## 6. 歌の選び方（取扱説明書 §6.2）

1. 「決まり字（グループ）」の一覧に、46 の決まり字グループを、決まり字表の順に並べる（仕様 01 §7）。各行は、グループの名前（例：あさ）。
2. グループの行を押すと、そのグループの歌がすべて選ばれていれば、すべて外す。そうでなければ、すべて選ぶ。
3. グループの行は、そのグループの歌がすべて選ばれているときだけ、選んだ表示になる。例：「あさ」を選ぶと、あさじ・あさぼらけあ・あさぼらけうの3首が選ばれ、「あさ」と「あさぼ」の行が選んだ表示になる。その後あさじを外すと、「あさ」の選んだ表示は消え、「あさぼ」は残る。
4. 「決まり字（個別）」の一覧に、100首を決まり字表の順に並べる。各行は「#087 む」の形（3桁の歌番号と静的決まり字）。行を押すと、その歌を選ぶ、または外す。
5. 「すべて選ぶ」で100首すべてを選び、「すべて外す」で0首にする。
6. 「決まり字を限定する」が OFF でも、歌は選べる。選んだ歌は、限定が ON のときだけ効く（仕様 03 §2）。

## 7. 範囲のある整数の入力

1. 半角の数字だけでできた入力を、整数として受け付ける。符号、小数点、空白、全角の数字などが入ったもの、空欄は受け付けない。範囲の外の数も受け付けない。
2. 受け付けない入力のときは、下書きを変えない。入力欄は打ったままにし、その欄に「1〜9999 の整数を入力してください。」の形で、受け付ける範囲を出す。
3. 受け付けない入力が1つでもある間は、「保存」を押せない。押せない見た目で残す。
4. 受け付ける入力に直すと、メッセージは消え、下書きが変わる。

## 8. 札の配置（取扱説明書 §6.3、ADR-0007 §4）

1. 「盤面の形」で、編集する形を選ぶ。8 つの形（6段×11列、6段×10列、6段×9列、6段×8列、4段×11列、4段×10列、4段×9列、4段×8列）から選ぶ。
2. 最初に開く形は、6段×11列。【判断待ち】ADR-0007 §4 は「最初は、今の画面の形を開く」とするが、盤面の周りに要る場所（画面の形を決める元）が、配置暗記の仕様まで決まらないため。
3. 選んだ形のマスを、上の段から順にチェック欄で並べる。上半分の段が相手陣、下半分の段が自陣で、間を空けて分ける。チェックありのマスを使う（仕様 03 §6.1）。
4. 各チェック欄の名前は「1段目 1列目」の形（段は上から、列は左から数える。仕様 03 §6.1）。
5. 形ごとに別々に持つ。ほかの形に切り替えても、変えた形の下書きは残る。
6. 初期値は、仕様 03 §6.1 の形ごとの図。6段×11列なら、各陣25マスで、中央に通路がある（B-27）。

## 9. 保存・初期値に戻す・トップへ戻る（取扱説明書 §6.4、ADR-0003 §6）

1. 「保存」は、下書きを保存する。保存できたら「保存しました。」と出す。保存できなかったら「保存できませんでした。」と出し、下書きはそのまま残す。
2. 保存の結果のメッセージは、その後に項目を変えると消す（今の下書きが保存されているかを取り違えないため）。
3. 「初期値に戻す」は、画面の値（受け付けない入力も含む）を初期値に戻すだけで、保存しない。確かめない（保存するまで、保存済みの値は変わらないため）。
4. 「トップへ戻る」は、保存していない変更を捨てて、トップ画面に戻る。確かめない（取扱説明書 §6.4 の決定のとおり）。ブラウザの「戻る」で離れたときも同じ。
5. 保存した値は、次に設定画面を開いたときも、各モードを始めるときも使う。「決まり字を限定する」を OFF で保存すれば、次に開いても OFF のまま（B-17）。
6. 一度も保存していないときは、設定画面も各モードも、同じ初期値を使う（B-26。設定の定義が1つなので、構造の上で一致する。ADR-0003）。

## 10. 定義から作る入力欄（ADR-0003 論点 D の決定）

- ON/OFF、範囲のある整数、選択肢の項目は、設定の定義の項目を順にたどって、入力欄を作る。範囲と選択肢は、定義から取る。
- 歌の選び方（§6）と札の配置（§8）は、専用の部品で作る。
- 項目の名前と選択肢の文言は、文言の表に持つ（ADR-0005）。定義のすべての項目に文言があることと、設定画面に入力欄があることを、テストで確かめる（ADR-0003 のテスト）。

## 12. テストへの落とし込み

### 12.1 受け入れテスト（E2E）

| ストーリー | 確かめること |
|---|---|
| トップから設定を開き、トップへ戻る | §2、§3.1 |
| 初めて開くと、すべて初期値 | §5、§8.6（B-26、B-27） |
| 項目を変えて保存すると、開き直しても残る | §9.1、§9.5（B-17） |
| 保存せずにトップへ戻ると、変更は捨てられる | §9.4 |
| 初期値に戻しても、保存はされない | §9.3 |
| グループで歌を選び、外す | §6 |
| 範囲の外の数では保存できない | §7 |
| 形を切り替えて配置を変え、保存する | §8 |

### 12.2 単体テスト・コンポーネントテスト

- 範囲のある整数と選択肢の項目の読み込み（ADR-0003 §4）、入力の受け付け（§7）。
- 編集の操作：項目の変更、受け付けない入力、歌の選び方、マスの切り替え。どの操作も、検証を通った値だけを下書きにする（ADR-0003 §8）。
- 定義のすべての項目に、文言と入力欄がある（§10）。
