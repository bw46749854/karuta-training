# 仕様 05: 札流し

- 状態：承認待ち（実装済み）
- 日付：2026-11-05（クラウドセッション。[指示書](../records/cloud-session-brief.md) §3 により、承認の前に実装した）

取り札を1枚ずつ見て、その札の決まり字を答える練習（取扱説明書 §2.1）。

根拠：

- 取扱説明書 §2（札流し）、§1.3（入力）、§8.1（決まったこと）
- [仕様 02](02-answer-input.md)（答えの入力と判定）、[仕様 03](03-questions-and-dealing.md) §2・§4（出題の対象、出題する札、札の向き）、[仕様 04](04-settings-and-top.md) §5.1・§5.2（設定の項目）
- [ADR-0004](../adr/0004-practice-mode-contract.md)（練習モードの共通の契約）、[ADR-0005](../adr/0005-wording.md)（文言）、[ADR-0006](../adr/0006-what-screens-show.md)（表示する情報）
- 不具合 B-01・B-02・B-17・B-21・B-22・B-24・B-25・B-26 の本来の動き

## 1. 用語

| 用語 | 意味 | コード上の名前 |
|---|---|---|
| 回 | 画面を開いてから、やり直すか離れるまでの1回の練習 | `session` |
| 問 | 1枚の札 | `question` |
| 出題する枚数 | 「出題枚数」と「出題の対象の数」の少ない方（仕様 03 §4） | `total` |
| 終わった問 | 判定したか、スキップした問 | `finished` |
| 結果 | 終わった問の、正解・誤答・スキップ（ADR-0004 §5） | `Outcome` |
| 変化 | 問が出た時点の決まり字が、静的決まり字より短いこと | `changed` |

## 2. 始め方と設定

1. トップ画面の「札流し」から開く。開くとすぐに1問目の札を出す（取扱説明書 §2.4）。
2. 開いたときに保存済みの設定を読み、その回のあいだは変えない（ADR-0003 §7）。一度も保存していなければ、設定画面と同じ初期値を使う（B-26）。
3. 使う設定：出題の範囲（決まり字を限定する、選んだ歌）と、札流しの項目（仕様 04 §5.2）。
4. 出題する札と札の向きは、仕様 03 §4 のとおり、乱数で決める。

## 3. 画面

上から次のものを出す。どれも、今の状態から作った表示だけを出す（ADR-0006 §3）。

1. 見出し「札流し」と「トップへ戻る」（仕様 04 §3.1）。
2. 進捗「n / N」とバー。n は終わった問の数、N は出題する枚数。「残り札」は出さない（ADR-0006 §6）。
3. 札。仮の札面で、歌番号だけを出す（[指示書](../records/cloud-session-brief.md) §4。決まり字は答えになるので出さない）。札の向きが逆さまなら、札を 180 度回して出す。終わったら札を出さない。
4. 答えの入力欄（名前「決まり字」）と「答える」ボタン。
5. 問を飛ばす・次へ進むボタン（§5）。
6. 判定（§4.3）。終わったら、終わったことのメッセージ（§6）。
7. 「やり直す」ボタン（§7）。
8. 決まり字一覧（§8）。

## 4. 答える

1. 入力欄の全体が答え（仕様 02 §2）。Enter か「答える」で判定する。
2. 空欄は受け付けない（仕様 02 §7、B-25）。空欄のあいだは「答える」を押せない見た目にし、Enter でも何も起きない。
3. 判定の表示（仕様 02 §6.1）：
   - 正解：「正解」
   - 不正解：「不正解：正解は ○○」（○○ は正解の決まり字）
   - かなに直せない答えのときは、不正解の表示に、理由を続けて出す（仕様 02 §5、B-22）。

     | 理由 | 文言 |
     |---|---|
     | かなとローマ字の混在 | かなとローマ字が混ざっています。 |
     | ローマ字入力が許可されていない | ローマ字入力は許可されていません。 |
     | 変換できないローマ字 | かなに直せないローマ字です。 |
     | ひらがなでもローマ字でもない | ひらがなかローマ字で入力してください。 |

4. 正解の決まり字（仕様 02 §6.3）：
   - 決まり字変化を考慮する OFF：静的決まり字（B-01）。
   - ON：「100首 − この回でそれより前に出た札」の中での決まり字。出た札には、答えた札もスキップした札も含む。限定しているかどうかは関係ない（B-02）。
5. 判定したら、答え直しはできない。入力欄は、入力したままの文字を、変えられない形で残す。

## 5. 問を飛ばす・次へ進む

1つのボタンの文言を、段階で変える（ADR-0005 §4）。

| 段階 | ボタン | 押したとき |
|---|---|---|
| 判定前 | スキップ | その問を「スキップ」として記録し、すぐ次の問へ進む。判定は出さない（取扱説明書 §2.5、§8.1） |
| 判定後 | 次へ | すぐ次の問へ進む |
| 終わった後 | 出さない | ―（B-24） |

- 「回答後に自動で次へ進む」が ON のときは、判定してから待機時間が経つと、次の問へ進む。待っている間に「次へ」を押すと、すぐ進む（取扱説明書 §2.4）。
- OFF のときは、「次へ」を押すまで判定を出したまま待つ。
- 最後の問の後に進むと、終わる（§6）。

## 6. 終わり

1. 出題する枚数の問がすべて終わった後に進むと、終わる。
2. 「お疲れさまでした。全問終了です。」と出し、札を消し、入力欄と「答える」を押せなくし、「スキップ」「次へ」を出さない（B-24）。進捗は「N / N」。
3. 終わった後にできるのは、「やり直す」「トップへ戻る」と、決まり字一覧を見ることだけ。

## 7. やり直す（取扱説明書 §2.10）

- どの段階でも押せる。出題する札と向きを新しく決め、1問目から始める。前の回の結果は何も残さない（ADR-0004 §6）。

## 8. 決まり字一覧（取扱説明書 §2.9）

1. 「決まり字一覧を開く」で開き、「決まり字一覧を閉じる」で閉じる。初めは閉じている（ADR-0007 §7）。
2. 出題の対象の歌を並べる。各行は「#057 め」の形（3桁の歌番号と静的決まり字）と、状態。
3. 状態：

   | 状態 | 意味 |
   |---|---|
   | 未読・初期 | まだ終わっていない。今の決まり字は、静的決まり字のまま |
   | 未読・変化中 | まだ終わっていない。今の決まり字が、静的決まり字より短い |
   | 正解・初期／正解・変化 | 正解した。「変化」は、問が出た時点で決まり字が変化していたこと |
   | 誤答・初期／誤答・変化 | 不正解だった。同上 |
   | スキップ・初期／スキップ・変化 | スキップした。同上（取扱説明書 §2.9 の【変更】。スキップを誤答と分ける） |

   - 「今の決まり字」は、「100首 − この回で終わった問の札」の中での決まり字。
   - 決まり字変化を考慮する OFF のときは、判定に静的決まり字を使うので、どの行も「初期」。
4. 状態は、判定やスキップのすぐ後に変わる（今の状態から表示を作るため。サンプルは次の札へ進んだときに変わっていた）。
5. 並び順は2つ。ボタンで切り替える。初めは決まり字順。
   - 決まり字順：決まり字表の順（「むすめふさほせ」…「あ」）。
   - 出題順：終わった問の札だけを、出題した順に並べる。
   - ボタンの文言は、押すと並ぶ順を書く：「出題順に並べる」「決まり字順に並べる」。

## 10. テストへの落とし込み

### 10.1 受け入れテスト（E2E）

E2E では、ページを読み込む前に `Math.random` を決めた値を返すものに差し替え、出る順を決める（ADR-0002 §5）。テストのための仕組みは、アプリに入れない。

| ストーリー | 確かめること |
|---|---|
| トップから開き、札と進捗を見て、トップへ戻る | §2、§3 |
| 一度も保存していなければ、設定画面と同じ初期値（出題枚数 100）で動く | §2.2（B-26） |
| 限定を OFF で保存すると、選んだ歌があっても100首から出す | §2.3（B-17） |
| 答えると、正解か、正解と理由が出る | §4.3（B-22） |
| 空欄では答えられない | §4.2（B-25） |
| スキップを続けると進捗が進み、終わる。終わった後はスキップできない。出題の対象が出題枚数より少なければ、対象を出し切って終わる | §5、§6（B-21、B-24） |
| 決まり字変化を考慮する OFF では、静的決まり字が正解。ON では変化した決まり字が正解。限定しても変化しない | §4.4（B-01、B-02） |
| 自動で次へ進む ON では、待機時間の後に次の問になる | §5 |
| 逆さまの札は、180 度回って見える | §3.3 |
| 一覧の状態と並び順 | §8 |
| やり直すと、1問目から始まる | §7 |

### 10.2 単体テスト

- 遷移関数：段階ごとに受け付ける操作。意味のない操作は状態を変えない（ADR-0004 §2）。今の問のものでない予約の出来事は、状態を変えない（ADR-0004 §3）。
- 判定の決まり字（変化 OFF・ON）、結果の記録、一覧の状態と並び順。
