# 仕様 03: 出題と札の配り方

各練習モードで、どの歌を、どの順で出題するかを定める。あわせて、配置暗記と実践練習の盤面に、どの札をどのマスへ配るかを定める。配置暗記と実践練習の出題は「場にある札」を使うので、配り方と同じ文書にする。

出題の範囲や順番は、どの歌を出すかだけを変える。正解（決まり字）は変えない（仕様 01 §6.1）。

この文書で定めないもの：

- 答えの判定。札流しと複数枚は [仕様 02](02-answer-input.md)。配置暗記（どのマスを選べば正解か）と実践練習（取るタイミング）は、各モードの仕様で定める。
- いつ配り直すか（画面を開いたとき、リセットしたときなど）と、出題の進め方。各モードの仕様で定める。
- 設定の値の持ち方と初期値。段階 3 の ADR で決める。

根拠：

- 取扱説明書 §1.1（出題の範囲）、§2.6・§2.7（札流し）、§3.3・§3.4・§3.8（複数枚）、§4.4・§4.7（配置暗記）、§5.7（実践練習）、§6.3（札の配置）
- 不具合 B-10（配置暗記の「空札を除外する」が効かない）の本来の動き
- 取扱説明書に書いていない細部は、サンプルのコードを読み、画面でも確かめた（§10）

## 1. 用語

| 用語 | 意味 | コード上の名前 |

## 2. 出題の対象

全モードで共通（取扱説明書 §1.1、確認済み）。

- 「決まり字を限定する」が ON で、1首以上選んでいる：選んだ歌。
- それ以外（OFF、または ON でも1首も選んでいない）：100首。

## 3. 「ランダム」の意味

- この文書で「ランダムに選ぶ」「ランダムな順」は、選び方と並べ方の手順に偏りがないことをいう。乱数が偏りなく与えられれば、どの選び方も、どの並びも、同じ確からしさで出る。
- 乱数は外から受け取る（設計方針 §2.3）。同じ乱数を与えれば、同じ結果になる。
- 乱数の形、作り方、偏りがないことの確かめ方は、[ADR-0002](../adr/0002-randomness.md) で決める。

## 4. 札流し

- **出題する札**：出題の対象からランダムに選んだ、「出題枚数」と「対象の数」の少ない方の枚数。ランダムな順に出す。同じ札は1回しか出ない（取扱説明書 §2.6）。
  - 例：出題枚数 4、対象 2首 → 2枚を出して終わる。
  - 例：出題枚数 4、対象 6首 → 6首のうち4枚を出して終わる。
- **札の向き**（取扱説明書 §2.7）
  - 正方向：すべて正しい向き。
  - 逆さま：すべて逆さま。
  - ランダム：1枚ごとに、正しい向きか逆さまかを、半々の確からしさで決める。ほかの札の向きとは関係なく決めるので、次の向きは予想できない。少ない枚数では、片方の向きに偏ることがある（例：3枚がすべて同じ向きになる確からしさは 25%）。

## 5. 札流し（複数枚）

- **出題する札**：札流しと同じ（§4）。出題枚数は、問の数ではなく札の総数（取扱説明書 §3.2）。
- **問への分け方**：出題する札を、出す順の先頭から同時枚数ずつ区切って、1つの問にする。最後の問は、残りの枚数になる（取扱説明書 §3.8）。
  - 例：出題枚数 6、同時枚数 5 → 5枚の問、1枚の問。
  - 例：出題枚数 4、同時枚数 2、対象 3首 → 2枚の問、1枚の問。
- **問の中の札の順**：区切った順に、1枚目、2枚目…とする。1枚目〜6枚目は、札を置く位置と、決まり字一覧での並びに使う（取扱説明書 §3.4）。
- **札の向き**：問ごとに決める。1つの問の中の札は、すべて同じ向き（取扱説明書 §3.3）。ランダムのときは、問ごとに、ほかの問とは関係なく半々の確からしさで決める（§4 と同じ考え方）。

## 6. 札の配り方（配置暗記・実践練習）

### 6.1 盤面と札の配置

- 盤面の形（段と列の数）は、画面の大きさに合わせて、6段か4段、11列から8列のどれかに決まる。決め方は [ADR-0007](../adr/0007-devices-and-screen-sizes.md) §2。この仕様は、決まった盤面の形を受け取って配る。
- 盤面の段は上から1、2、…、列は左から1、2、…と数える。上半分の段が相手陣、下半分の段が自陣。
- 札の配置（どのマスを使うか）は、盤面の形ごとに持つ。利用者は、形ごとに変えられる（ADR-0007 §4。変え方は設定画面の仕様）。
- 札は、使うマスにだけ置く。
- 1回の練習の間（配置暗記で配ってから、実践練習を終えるまで）は、盤面の形を変えない（ADR-0007 §5）。

**初期の配置**（○が使うマス、・が使わないマス）：

- どの形も、相手陣は自陣を180度回したもの。各陣の使うマスは同じ数。
- 今の6段×11列の初期値（取扱説明書 §6.3、決定済み）と同じ考え方で決めた。各陣の手前の段は9枚、ほかの段は8枚、余った列を真ん中の通路にする。列が足りなければ、その段の列の数まで。

### 6.2 配る札

1. 出題の対象から、使うマスの数（両陣の合計）までの札をランダムに選ぶ。対象の方が少なければ、対象を全部選ぶ。
2. 選んだ札の半分（端数は切り捨て）を相手陣に、残りを自陣に配る。例：7枚なら、相手陣に3枚、自陣に4枚。
   - 片方の陣の使うマスが足りないときは、入りきらない分を、もう片方の陣に回す。両陣の使うマスの数が違う配置でも、使うマスがある限り札を置き、選んだ札はすべて配る。
   - 例：相手陣 33マス、自陣 10マス、出題の対象 100首 → 43枚を選ぶ。半分ずつなら相手陣 21枚、自陣 22枚だが、自陣は 10マスなので、入りきらない 12枚を相手陣に回す。相手陣 33枚、自陣 10枚。
3. どの札をどちらの陣のどのマスに置くかも、ランダムに決める。


### 6.3 置くマス

各陣で、自分から見て手前の段から順に詰めて置く（取扱説明書 §4.4）。

- 相手陣：段1の左端の列から右へ。段1の使うマスが埋まったら段2、と下へ進み、相手陣のいちばん下の段まで。
- 自陣：いちばん下の段の右端の列から左へ。その段の使うマスが埋まったら一つ上の段、と上へ進み、自陣のいちばん上の段まで。
- 6段×11列の盤面なら、相手陣は段1の列1から段3まで、自陣は段6の列11から段4まで。
- 使わないマスは飛ばす。札が足りなければ、残りの使うマスは空いたままになる。

例：

| 盤面の形・札の配置 | 出題の対象 | 相手陣 | 自陣 |
|---|---|---|---|
| 6段×11列・66マスすべて | 10首 | 段1の列1〜5（5枚） | 段6の列7〜11（5枚） |
| 6段×11列・66マスすべて | 100首 | 33マスすべて | 33マスすべて |
| 6段×11列・初期値 | 100首 | 25マスすべて | 25マスすべて |
| 6段×11列・初期値 | 7首 | 段1の列1〜3（3枚） | 段6の列8〜11（4枚） |
| 4段×8列・初期値 | 100首 | 16マスすべて | 16マスすべて |
| 4段×8列・初期値 | 7首 | 段1の列1〜3（3枚） | 段4の列5〜8（4枚） |
| 4段×11列・初期値 | 10首 | 段1の列1〜5（5枚） | 段4の列7〜11（5枚） |
| 6段×9列・初期値 | 100首 | 25マスすべて | 25マスすべて |

出題の対象のうち、配らなかった札は、場にない札（空札）になる。

## 7. 配置暗記の出題

- **問の種類**
  - グループの問：決まり字グループ（仕様 01 §7）を1つ出す。
  - 個別の問：歌を1首出す。
- **出題モード**（取扱説明書 §4.7）
  - グループ：出題の対象の歌を1首以上含むグループを、すべて出す。「あ」と「あさ」のように重なるグループも、それぞれ1問。
  - 個別：出題の対象の歌を、すべて出す。
  - 混合：グループの問と個別の問を、すべて混ぜて出す。
- **空札を除外する**（取扱説明書 §4.7、B-10）
  - ON：個別の問は、場にある札だけ。グループの問は、場にある札を1枚以上含むグループだけ。
  - OFF：場にない札も、場に1枚もないグループも出す。
- **順番**：すべての問を、ランダムな順で1回ずつ出す。混合では、グループの問と個別の問が混ざった順になる。

## 8. 実践練習の読む札

- 空札を除外する ON：出題の対象のうち、場にある札だけを読む（取扱説明書 §5.7）。
- OFF：出題の対象をすべて読む。場にない札は、空札として読む。
- ランダムな順で、すべて1回ずつ読む。

## 10. 現行サンプルとの対応

| 項目 | 現行サンプル | 新しい版 |
|---|---|---|
| 乱数 | 各画面が `Math.random` を直接呼ぶので、テストで結果を決められない。シャッフルは5か所とも Fisher–Yates 法で、手順に偏りはない | ポートを通して外から受け取る。テストでは決めた値を与える（§3、ADR-0002） |
| 札の向き（ランダム） | 札流しは1枚ごと、複数枚は問ごとに、ほかと関係なく半々 | 同じ（§4、§5） |
| 配置暗記の「空札を除外する」 | 効かない。場にない札も、場に1枚もないグループも出る（B-10） | §7 のとおり効く |
| 両陣の使うマスの数が違う配置 | 半分ずつに分け、入りきらない札は置かない。使うマスが空いたまま残る（§10.1） | 入りきらない分をもう片方の陣に回し、選んだ札はすべて配る（§6.2） |
| 盤面の形 | 6段×11列で、大きさも決まっている。小さい画面では切れる（取扱説明書 §4.2） | 画面に合わせて段と列の数を決める。札の配置は形ごとに持つ（§6.1、ADR-0007） |
| そのほか（出題の対象、札流し・複数枚の枚数と問への分け方と向き、配り方、配置暗記の問の作り方、実践練習の読む札） | この文書と同じ（コードで確認） | 同じ |

### 10.1 サンプルで確かめたこと

2026-10-31 に、サンプル（タグ `sample`）の設定画面で、限定を外し（100首）、相手陣は33マスすべて、自陣は段6の列2〜11の10マスだけを使う配置にして保存した。配置暗記を開くと、相手陣に21枚（段1に11枚、段2に10枚）、自陣に10枚が配られ、相手陣の段3は、使うマスなのに空いたままだった（Chromium で画面を確認。2回開いて同じ）。

コード（`memorize-placement.js` の `pickNumbers` と `applyDistribution`）では、使うマスの合計（43）まで札を選び、相手陣に半分の21枚、自陣に残りの22枚を割り当てる。自陣は10マスしかないので10枚だけを置き、残りの12枚は置かない。
