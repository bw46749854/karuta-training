# 仕様 07: 配置暗記

- 状態：承認待ち（実装済み）
- 日付：2026-11-05（クラウドセッション。仕様を書いた後、ユーザーの求めで実装した。[指示書](../records/cloud-session-brief.md) §3 により、承認の前に実装した）

盤面に並べた札の位置を覚える練習。出題された決まり字の札がどこにあるかを、盤面のマスを選んで答える（取扱説明書 §4.1）。

根拠：

- 取扱説明書 §4（配置暗記）、§6.3（札の配置）、§8.1（決まったこと）
- [仕様 03](03-questions-and-dealing.md) §6（盤面と札の配り方）・§7（配置暗記の出題）、[仕様 04](04-settings-and-top.md) §5.4（設定の項目）、[仕様 05](05-card-flow.md)・[仕様 06](06-multiple-card-flow.md)（そろえる所）
- [ADR-0004](../adr/0004-practice-mode-contract.md) §8（実践練習への受け渡し）、[ADR-0005](../adr/0005-wording.md)、[ADR-0006](../adr/0006-what-screens-show.md)、[ADR-0007](../adr/0007-devices-and-screen-sizes.md)（盤面の形、横向きだけ、操作の対象の大きさ）
- 不具合 B-10・B-11・B-12・B-13 の本来の動き

## 1. 用語

| 用語 | 意味 | コード上の名前 |
|---|---|---|
| 盤面の形 | 段と列の数（ADR-0007 §2） | `BoardShape` |
| 覚える時間 | 出題を始める前。札を裏返して覚える | `memorizing` |
| 出題中 | 問を出し、マスを選んで答える段階 | `asking` |
| 選んだマス | 出題中に、答えとして選んだマス | `selected` |
| 正解のマス | 問の札が置かれたマス（§5.3） | — |
| 札の確認 | 判定の後に、札を裏返して確かめること（取扱説明書 §4.6） | `checking` |

## 2. 始め方と画面の向き

1. トップ画面の「配置暗記」から開く。開くと、札を配って、覚える時間になる（取扱説明書 §4.4）。
2. 盤面を使うので、横向き（幅が高さ以上）のときだけ使える。縦向きのときは「横向きにしてください。」と出す（ADR-0007 §3）。PC で縦長の窓のときも同じ。
3. 盤面の形は、開いたときの盤面の領域の大きさで、ADR-0007 §2 の境で決める。4段×8列でも入らないときは「この画面の大きさでは、盤面を使う練習はできません。」と出す（ADR-0007 §8）。
   - 盤面の領域は、画面から、見出しの段と、右の操作の欄（§3.2。幅 240）と、その間（16）を除いた所。実際の大きさを測って決める。右の欄の幅は、画面の配置の細部として決めた（段階 5 で見直す）。
   - 【判断待ち】仕様 04 §8.2（設定画面で最初に開く形）は、設定画面からはこの領域を測れないので、6段×11列のまま。今の画面の形を開くには、設定画面でこの画面の配置を見積もる形にするか、ADR-0007 §4 を直すかを決める。
4. 1回の練習の間は、盤面の形を変えない（ADR-0007 §5）。画面の大きさが変わったら、札の大きさだけを合わせ直す。
5. 札の配置は、設定の、その形の配置を使う（仕様 03 §6.1）。

## 3. 画面

1. 見出し「配置暗記」と「トップへ戻る」。
2. 左に盤面、右に操作の欄（決まり字の一覧、ボタン、問、判定）（取扱説明書 §4.2）。
3. 盤面：
   - 上半分の段が相手陣、下半分の段が自陣。相手陣の札は逆さまに出す（取扱説明書 §4.2）。
   - 札は仮の札面（歌番号だけ。[指示書](../records/cloud-session-brief.md) §4）。裏の札は白紙の札。
   - 札のないマスは、使わないマスも、空いたマスも、何も出さない。
   - マスは押せる対象なので、札の幅は 44 以上（ADR-0007 §6）。
4. 決まり字の一覧（グループ、個別）は、場にある札のものだけを出す。個別は「#087 む」の形、グループは名前（例：あさ）。

## 4. 覚える時間（取扱説明書 §4.5）

| 操作 | 動き |
|---|---|
| 盤面の札を押す | その札を裏返す。もう一度押すと表に戻る |
| 個別の一覧の行を押す | その札を裏返す（表に戻す） |
| グループの一覧の行を押す | そのグループの、場にある札をまとめて裏返す。すべて裏なら、まとめて表に戻す |
| 「表と裏を入れ替える」 | 盤面のすべての札の表と裏を入れ替える |
| 「配り直す」 | 新しく配り直し、すべての札を表にする。前の盤面の裏返しは残らない（B-13） |
| 「出題を始める」 | 出題中になる（§5） |

- 個別の一覧の行は、その札が裏のときに選んだ表示。グループの行は、そのグループの場にある札がすべて裏のときに選んだ表示（取扱説明書 §4.5）。
- ボタンの文言は、押すと起きることを書く（ADR-0005 §4）。サンプルの「表示反転」「リセット」「出題開始」を、それぞれ「表と裏を入れ替える」「配り直す」「出題を始める」にする。

## 5. 出題（取扱説明書 §4.6、仕様 03 §7）

1. 「出題を始める」で、盤面の札をすべて裏にし、1問目を出す。出題中は、一覧と「表と裏を入れ替える」「配り直す」を使えない（押せない見た目で残す）。
2. 問は、決まり字の文字で出す（グループはその名前、個別はその歌の静的決まり字）。「問：あさ」の形。出題モードと「空札を除外する」は、仕様 03 §7 のとおり（B-10）。出題を始めるたびに、問の順を新しく決める。
3. 正解のマス：
   - 個別の問：その札が場にあれば、そのマス。場になければ、正解のマスはない（何も選ばずに答えるのが正解）。
   - グループの問：静的決まり字がそのグループの名前で始まる札のうち、場にあるもの**すべて**のマス。
4. マスを押すと、選ぶ。もう一度押すと、選ぶのをやめる。選んだマスは、白い札で出す。
5. 「答える」で判定する。選んだマスが正解のマスと**ちょうど同じ**なら「正解」、そうでなければ「誤答」（取扱説明書 §4.6）。
6. 判定の後：
   - 「回答後に正解札を表示」（する／しない／正答時のみ／誤答時のみ）に従い、正解のマスの札を表にする。
   - 「回答後に札の確認を許可」に従い、許可のときは、盤面の札と一覧で裏返して確かめられる。この2つの設定は、別々に効く（B-11）。
7. 次へ進む：
   - 判定前のボタンは「スキップ」。押すと、その問を「スキップ」として記録し、次の問へ進む（取扱説明書 §4.6 の【変更】）。
   - 判定後のボタンは「次へ」。「回答後に自動で次へ進む」が ON なら、待機時間の後に次の問になる（B-12）。
   - 次の問へ進むとき、盤面の札はすべて裏に戻し、選んだマスは消す。
8. 進捗「n / N」とバー。n は終わった問の数、N は問の数。
9. 全部の問が終わった後に進むと、「出題はすべて終わりました。」と出し、覚える時間に戻る（札はすべて表）。この知らせは、その後に札を裏返すと消す（設定画面の保存の知らせと同じ考え方。仕様 04 §9.2）。
10. 「出題を終える」で、いつでも覚える時間に戻る（札はすべて表）（取扱説明書 §4.6）。それまでの結果は残さない。

## 6. 結果

- 問ごとに、正解・誤答・スキップを記録する（ADR-0004 §5）。回の中でだけ持ち、保存しない。
- 結果の一覧を画面に出すかは、この仕様では決めない（サンプルにない。§11 の提案）。

## 7. 実践練習との行き来（取扱説明書 §4.8、ADR-0004 §8）

- 「プレイ開始」（覚える時間だけ押せる）、盤面の保存（`BoardRepository`）、戻ったときの盤面の扱いは、[仕様 08](08-play.md) §2・§7 で決めた。

## 9. 決めたこと（この仕様の中で）

| 論点 | 決めたこと | 理由 |
|---|---|---|
| 一覧に出す歌 | 場にある札だけ | 場にない札の行は、押しても何も起きない。押せない行を並べない（ADR-0006 §4） |
| 出題中の一覧とボタン | 押せない見た目で残す | 判定の後の札の確認で、また使えるようになるため、場所を変えない |
| 次の問へ進むときの盤面 | すべて裏に戻し、選んだマスを消す | 前の問の何かが次の問に残らない（ADR-0004 §3、B-07 と同じ種類） |
| 「出題を終える」の結果 | 残さない | 回の途中の結果を見せる画面がないため（§6） |
| 問の順を作る所 | 「出題を始める」のたびに、画面が `Random` ポートで新しい順を作り、始める操作と一緒に渡す | 遷移関数は乱数を使わない（ADR-0004 §6）。同じ盤面で始め直しても、同じ順にならない |
| 伏せた札と選んだマスの見た目 | 伏せた札は札の裏（緑）、選んだマスは白い札 | 取扱説明書 §4.6「タップしたマスは白い札になる」と区別するため |

## 10. テストへの落とし込み

### 10.1 受け入れテスト（E2E）

盤面を使う画面なので、ADR-0007 §10 の大きさ（iPad 横、Steam Deck、スマートフォン横）と、縦向きの案内（iPad 縦、スマートフォン縦）で確かめる。出る順と配り方は、`Math.random` を決めた値にして決める（ADR-0002 §5）。

| ストーリー | 確かめること |
|---|---|
| 開くと、札の配置のとおりに配られ、相手陣の札が逆さまに見える | §2、§3（B-27 の盤面の側） |
| 札・個別・グループで裏返し、表と裏を入れ替え、配り直すとすべて表になる | §4（B-13） |
| 個別の問で、何も選ばずに答えると、場にある札なら誤答 | §5.3（B-10） |
| グループの問で、場にあるすべての札を選ぶと正解 | §5.3、§5.5 |
| 正解札の表示と、札の確認の許可が、別々に効く | §5.6（B-11） |
| 自動で次へ進む ON では、待機時間の後に次の問になる | §5.7（B-12） |
| 判定前の「スキップ」、終わり、「出題を終える」 | §5.7、§5.9、§5.10 |
| 縦向きでは横向きにする案内が出る。盤面が入らない大きさでは、使えないと出る | §2.2、§2.3 |
| 途中で縦向きにして横向きに戻すと、続きから練習できる | §2.4（ADR-0007 §5） |
| ADR-0007 §10 の大きさで、横向きなら盤面・問・ボタン・判定が1画面に収まる | §2、§3（ADR-0007 §7） |

### 10.2 単体テスト

- 盤面の形を領域の大きさで決める関数（ADR-0007 §2 の境の前後）。
- 遷移関数：段階ごとに受け付ける操作、正解のマスの求め方（個別・グループ・空札）、判定、正解札の表示と確認の許可の組み合わせ、自動で次へ、今の問のものでない予約の無視。

## 11. 提案（仕様に入れていないもの）

- 出題の回の結果（正解・誤答・スキップの数や、間違えた問）を、終わったときに出す。
