# 仕様 08: 実践練習

- 状態：承認待ち（未実装）
- 日付：2026-11-05（クラウドセッション。仕様だけを書いた。品質を優先し、残りの時間では実装を始めなかった）

配置暗記の盤面を使い、決まり字が1文字ずつ出るのを見て、その札を取る（押す）練習。札の位置を覚えているかと、取るタイミングを練習する（取扱説明書 §5.1）。

## 1. 用語

| 用語 | 意味 | コード上の名前 |
|---|---|---|
| 読む | 問の歌の静的決まり字を、1文字ずつ出すこと | `reading` |
| 文字間隔 | 1文字を出してから次の文字を出すまでの時間（設定） | `letterIntervalMs` |
| 決まる文字 | その時点の決まり字の最後の文字（取扱説明書 §5.6） | `decidingLetter` |
| 取る | 盤面の札を押すこと。1問につき最初の1回だけが有効 | `take` |
| 取れる間 | 決まる文字を出した時刻から、文字間隔の長さの間 | `window` |

## 2. 始め方と盤面の受け渡し（ADR-0004 §8）

1. 配置暗記の覚える時間に「プレイ開始」を足す（仕様 07 §7）。押すと、今の盤面（どのマスにどの札があるか）を保存して、実践練習を開く。札の表と裏は渡さない（実践練習では、札はすべて表。取扱説明書 §5.2）。
2. 盤面は、設定とは別の保存データにする（ADR-0003 §3）。ポートは `BoardRepository`。保存した文書をそのまま出し入れし、検証は `application` が行う（設定と同じ形。ADR-0003 §5）。文書は版の番号と、盤面の形とマスごとの歌番号を持つ。形が8つのどれでもない、マスの数が合わない、歌番号が正しくない、同じ歌が2回ある文書は、盤面がないものとして扱う。
3. トップ画面には実践練習へのボタンを出さない（取扱説明書 §7.1）。
4. 盤面がないとき（保存していない、読めない）は、「盤面がありません。配置暗記で札を配ってから始めてください。」と、配置暗記の画面へ移るボタン「配置暗記へ」を出す（B-14）。
5. 開くとすぐに1問目を読み始める（取扱説明書 §5.4）。
6. 盤面の形は保存した盤面の形のまま変えない（ADR-0007 §5）。札の大きさは、画面の盤面の領域に合わせる。その形で札の幅が 44 に届かない画面では、仕様 07 §2.3 と同じく使えないことを伝える。横向きだけ（ADR-0007 §3）。縦向きの間は案内を出し、回は保つ。

## 3. 読む札（仕様 03 §8）

- 空札を除外する ON：出題の対象のうち、場にある札だけを読む。
- OFF：出題の対象をすべて読む。場にない札は空札として読む。
- ランダムな順で、すべて1回ずつ読む。順は、回を始める前に `Random` ポートで作る（ADR-0004 §6）。

## 4. 1問の流れ（取扱説明書 §5.5）

1. 問の歌の静的決まり字を、文字間隔ごとに1文字ずつ出す。決まり字変化で短くなっていても、静的決まり字のすべての文字を出す（例：あさぼらけあ なら、あ、さ、ぼ、ら、け、あ）。
2. 盤面の札を押すと、その札を取ったことにする。1問につき、最初の1回だけが有効。2回目からは何も起きない。
3. 最後の文字を出してから文字間隔の後に、判定を出す（§5）。最後の文字の前に取っても、判定は最後の文字の後に出す。
4. 読んだ札は、正誤に関係なく、場から取り除く（判定を出すときに）。
5. 次の問へ：
   - 回答後に自動で次へ進む ON：判定を出してから待機時間の後に、次の問を読む。
   - OFF：「次へ」を押す。
6. 全部読んだ後に進むと、「すべての札を読みました。」と出す。

## 5. 判定（取扱説明書 §5.6）

- 決まる文字は、「100首 − この回で読んだ歌」の中での決まり字の、最後の文字（仕様 01 §6.2）。出題の対象を限定しているか、空札を除外しているかは関係ない（B-15）。
  - 例：「うか」だけを読む回で、「うら」がまだ読まれていなければ、うか の決まる文字は「か」。
- 時刻は、出来事に付いて届く時刻を使う（ADR-0004 §3）。

| 状況 | 結果 | 文言 |
|---|---|---|
| 場にある札が読まれ、取れる間にその札を取った | 正解 | 正解 |
| 同上で、決まる文字を出す前に取った | 誤答（早い） | 早い：0.25 秒（決まる文字を出すまでの秒数。小数第2位まで） |
| 同上で、取れる間より後に取った | 誤答（遅い） | 遅い：0.25 秒（取れる間の終わりからの秒数） |
| 場にある札が読まれ、違う札を取った | 誤答（違う札） | 違う札を取りました |
| 場にある札が読まれ、どの札も取らなかった | 誤答（取らなかった） | 取れませんでした |
| 空札が読まれ、どの札も取らなかった | 正解（空札） | 正解（空札） |
| 空札が読まれ、どれかの札を取った | 誤答（違う札） | 違う札を取りました |

- 【判断待ち】サンプルの「ズレ」（取った札は合っているが、早い・遅い）を、誤答として記録する。共通の結果は正解・誤答・スキップの3つなので（ADR-0004 §5）、どちらかに入れる必要がある。早い・遅いの区別と秒数は、実践練習の結果の型に持つ。
- 文言は、ADR-0005 §4（理由は入力に合わせる、です・ます）に合わせてサンプルから変えた。段階 5 で全体を見直す。

## 6. 読んでいる途中の「スキップ」（取扱説明書 §5.8、B-16）

- 読んでいる途中のボタンは「スキップ」、判定の後は「次へ」（ADR-0005 §4。仕様 05 §5 と同じ）。
- 「スキップ」を押すと、その問の文字の表示・取れる間・判定の予約をすべて取り消し、その問を「スキップ」として記録し、その札を場から取り除いてから、次の問を読み始める。前の問の何かが、次の問に残らない（ADR-0004 §3：予約に問の番号を付け、今の問のものでない出来事は無視する）。

## 7. 画面

1. 見出し「実践練習」と「トップへ戻る」。
2. 左に盤面（配置暗記と同じ並び。相手陣の札は逆さま）。札はすべて表。取り除いた札のマスは空く。
3. 右の欄に、読んでいる文字（それまでに出した文字を並べる）、判定、進捗「n / N」（N は読む札の数）、ボタン「スキップ／次へ」「プレイ終了」。
4. 決まり字の一覧は出さない（取扱説明書 §5.2 では出しているが、プレイ中は操作しないため。ADR-0006 §1 の目的に当たらない）。【判断待ち】出す必要があれば、仕様に足す。
5. 「プレイ終了」を押すと、配置暗記に戻る。配置暗記は、保存した盤面（取り除いた札も元に戻した並び）で、覚える時間から始める（取扱説明書 §4.8、§5.9）。
6. 配置暗記をトップ画面から開いたとき、または再読み込みしたときは、新しく配る（取扱説明書 §4.8）。

## 8. 結果

- 問ごとに、正解・誤答・スキップと、実践練習の詳しい結果（早い・遅いと秒数、違う札、取らなかった、空札）を記録する。回の中でだけ持ち、保存しない（ADR-0004 §5）。
- 結果の一覧を画面に出すかは、この仕様では決めない（サンプルにない。仕様 07 §11 と同じ提案）。

## 10. テストへの落とし込み

### 10.1 受け入れテスト（E2E）

文字間隔と待機時間は短くし、`Math.random` を決めた値にする（ADR-0002 §5）。取るタイミングの境は、単体テストで偽の時計を使って確かめる（E2E では、早い・取れる間・遅いの代表だけ）。

| ストーリー | 確かめること |
|---|---|
| 配置暗記の「プレイ開始」で、同じ盤面のまま実践練習が始まる | §2.1 |
| 盤面がないときは、メッセージと「配置暗記へ」が出る | §2.4（B-14） |
| 決まり字が1文字ずつ出て、取れる間に取ると正解、早いと「早い」 | §4、§5 |
| 1首だけに限定しても、まだ読まれていない歌で決まる文字が変わらない | §5（B-15） |
| 読んでいる途中のスキップで、前の問が次の問に残らない | §6（B-16） |
| 「プレイ終了」で、元の盤面の配置暗記に戻る | §7.5 |

### 10.2 単体テスト

- 盤面の文書の読み込み（ない、壊れた、形が違う、歌番号が正しくない、同じ歌が2回）と、保存先の契約テスト。
- 遷移関数：文字を出す予約、取る（最初の1回だけ）、判定の表の各行、取れる間の境（ちょうど決まる文字の時刻、取れる間の終わり）、スキップで予約を取り消すこと、今の問のものでない予約の無視、札を場から取り除くこと、自動で次へ。
