# 仕様 00: 現行サンプルの挙動の棚卸し

現行サンプル（main ブランチ c6423a1）の挙動を1つずつ洗い出し、意図したものかどうかを確認する。
新設計の仕様には、ここで「意図どおり」と確認した挙動だけを引き継ぐ。

サンプルにない機能は、この文書にも仕様にも書かない。必要になった場合は「提案」として別に示し、承認されてから仕様に入れる。

**凡例**

- 意図：✅ 意図どおり（確認済み） / ❌ 意図していない（確認済み） / ❓ 未確認 / 🔍 未調査
- 根拠：実行 ＝ サンプルを実際に動かして確認、コード ＝ コードを読んで確認

## 1. 確認済みの方針

| 日付 | 内容 |
|---|---|
| 2026-10-30 | 「決まり字を限定する」は、出題する歌を絞り込むだけ。決まり字の計算には影響しない |
| 2026-10-30 | 札流しの正解は静的決まり字（100首での決まり字） |
| 2026-10-30 | 決まり字変化札流しの正解は「100首 − めくった札」で計算する |
| 2026-10-30 | 決まり字変化は、実際に出題された（読まれた）歌だけを考慮する。限定しているかどうかは関係ない |
| 2026-10-30 | 実践練習は配置暗記の実践。札の位置を覚えていなければ不正解なので、違う札に触れたら不正解 |
