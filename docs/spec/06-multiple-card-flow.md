# 仕様 06: 札流し（複数枚）

- 状態：承認待ち（実装済み）
- 日付：2026-11-05（クラウドセッション。[指示書](../records/cloud-session-brief.md) §3 により、承認の前に実装した）

複数の取り札を同時に一定時間だけ見せ、伏せた後で、全部の札の決まり字を答える練習（取扱説明書 §3.1）。

根拠：

- 取扱説明書 §3（札流し（複数枚））、§8.1（決まったこと）
- [仕様 02](02-answer-input.md) §3・§6.2・§6.3・§7（複数枚の答え、判定、受け付けない入力）、[仕様 03](03-questions-and-dealing.md) §5（出題する札、問への分け方、札の向き）、[仕様 04](04-settings-and-top.md) §5.3（設定の項目）、[仕様 05](05-card-flow.md)（札流し。共通にできる所はそろえる）
- [ADR-0004](../adr/0004-practice-mode-contract.md)、[ADR-0005](../adr/0005-wording.md)、[ADR-0006](../adr/0006-what-screens-show.md)
- 不具合 B-03・B-04・B-05・B-06・B-07・B-08・B-09・B-19・B-20・B-25 の本来の動き

## 1. 用語

| 用語 | 意味 | コード上の名前 |
|---|---|---|
| 問 | 同時に出す札のまとまり。同時枚数ぶん（最後の問は残りの枚数。仕様 03 §5） | `question` |
| 問の札の枚数 | その問に実際に出ている札の枚数 | — |
| 札の位置 | 問の中の 1枚目〜6枚目（仕様 03 §5） | `position` |
| 伏せる | 札を白紙の札にする。位置は残す | `hidden` |
| 出題する枚数 | 札の総数。「出題枚数」と「出題の対象の数」の少ない方（仕様 03 §4・§5） | `total` |

## 2. 始め方と設定

1. トップ画面の「札流し（複数枚）」から開く。開くとすぐに1問目を出す。
2. 開いたときに保存済みの設定を読み、その回のあいだは変えない（ADR-0003 §7）。
3. 使う設定：出題の範囲と、複数枚の項目（仕様 04 §5.3）。決まり字変化を考慮する（B-05）、ローマ字入力を許可（B-03）も、そのとおりに効かせる。

## 3. 画面

1. 見出し「札流し（複数枚）」と「トップへ戻る」。
2. 進捗「n / N」とバー。n は終わった札の枚数、N は出題する枚数（問の数ではない。取扱説明書 §3.2）。「残り札」は出さない（ADR-0006 §6）。
3. 札の枠（3列×2段）。札は次の位置に置く（取扱説明書 §3.4）。空いた位置は空欄のまま。

   | 上段左：6枚目 | 上段中：4枚目 | 上段右：3枚目 |
   |---|---|---|
   | **下段左：5枚目** | **下段中：2枚目** | **下段右：1枚目** |

   - 逆さまの問では、枠ごと 180 度回す（取扱説明書 §3.4）。
   - 出すのは今の問の札だけ。前の問の札は残さない（B-07）。
4. 答えの入力欄（名前「決まり字」）、「答える」、問を飛ばす・次へ進むボタン（仕様 05 §5 と同じ）。
5. 判定と、受け付けない入力のメッセージ（§5）。判定の前は何も出さない（サンプルの「未開始」は出さない。ADR-0006 §6 の当てはめ）。
6. 「やり直す」と決まり字一覧（§8）。

## 4. 問の流れ（取扱説明書 §3.5）

1. 問が始まると、札を表で出す。出現時間が経つと、札を伏せる（白紙の札。位置は残す）。
2. 伏せる前から答えてよい。
3. 判定したら、伏せていた札を表に戻す。伏せる前に判定したときは、伏せない。
4. 次の問へ進むと、前の問の予約（伏せる、自動で次へ）は取り消す（ADR-0004 §3）。

## 5. 答える（仕様 02 §3・§6.2・§7）

1. 問の札の枚数ぶんの答えを、1行に区切りの文字で分けて入れ、Enter か「答える」で、その場で判定する。
2. 受け付けない入力では、判定しない。

   | 入力 | 動き | 文言 |
   |---|---|---|
   | 空欄 | 何も起きない。「答える」は押せない見た目（B-25。仕様 05 §4.2 と同じ） | ― |
   | 区切りだけ | メッセージを出し、入力欄を空にする | 区切りの文字だけでは、答えになりません。 |
   | 答えが問の札の枚数より多い | メッセージを出し、入力欄を空にする | 答えが札の枚数より多いので、受け付けませんでした。札の枚数までにしてください。 |

3. 判定の表示：問が正解なら「正解」、不正解なら「不正解」。札ごとの正誤は、決まり字一覧に出す（§8）。
4. 正解の決まり字は、問が出た時点の候補集合で求める（仕様 02 §6.3）。同じ問の中では変えない。最後の問が1枚だけでも同じ（B-06）。
5. 判定したら、答え直しはできない。

## 6. 問を飛ばす・次へ進む

仕様 05 §5 と同じ。

- 判定前の「スキップ」は、その問のすべての札を「スキップ」として記録し、すぐ次の問へ進む（取扱説明書 §3.9、B-19）。
- 判定後は「次へ」。自動で次へ進む ON なら、待機時間の後に次の問へ進む（B-04）。

## 7. 終わり

- 出題する枚数の札がすべて終わった後に進むと、終わる。「お疲れさまでした。全問終了です。」と出し、札を消し、入力と「スキップ」「次へ」をできなくする（B-08）。進捗は「N / N」。

## 8. 決まり字一覧（取扱説明書 §3.10）

札流しの一覧（仕様 05 §8）と同じ。違うところだけを書く。

1. 出題の対象の歌だけを並べる（B-20）。
2. 正誤は札ごと（仕様 02 §6.2）。問が不正解でも、決まり字が答えの中にある札は「正解」。
3. 「変化」は問ごとに決める。その問が出た時点で、その札の決まり字が変化していたか。
4. 出題順は、終わった問を出題した順に、同じ問の中は 1枚目、2枚目…6枚目の順に並べる（B-09）。

## 9. やり直す

仕様 05 §7 と同じ。

## 11. テストへの落とし込み

### 11.1 受け入れテスト（E2E）

E2E では、仕様 05 と同じく `Math.random` を決めた値にし、出る順を決める。出現時間は短くし、伏せる前と後を見る。

| ストーリー | 確かめること |
|---|---|
| 札が出現時間の後に伏せられ、判定すると表に戻る | §4 |
| 答えると判定し、自動で次へ進む ON なら次の問になる。OFF なら「次へ」で進む | §5、§6（B-04） |
| ローマ字入力を許可していれば、ローマ字で答えられる | §2.3（B-03） |
| 空欄・区切りだけ・多すぎる答えは受け付けない | §5.2（B-25） |
| 決まり字変化を考慮する ON では、前の問の札で決まり字が変わる。最後の1枚の問でも 100首から計算する | §5.4（B-05、B-06） |
| 端数の1枚の問で、前の問の札が残らない | §3.3（B-07） |
| 終わったことが出て、進捗が N / N になる | §7（B-08） |
| 一覧は出題の対象だけで、札ごとの正誤、スキップ、問ごとの変化が出る。出題順は問の中の位置の順 | §8（B-09、B-19、B-20） |
| 6枚の札が、§3.3 の位置に並ぶ | §3.3 |
| 練習の中心の領域が、ADR-0007 §10 のどの大きさでも1画面に収まる。2段の札は、低い画面では小さくする | §3（ADR-0007 §7） |

### 11.2 単体テスト

- 遷移関数：段階ごとに受け付ける操作、伏せる予約と自動で次への予約、今の問のものでない予約の出来事の無視（ADR-0004 §2・§3）。
- 判定の決まり字（変化 OFF・ON、最後の1枚の問）、札ごとの結果、一覧の状態と並び。
