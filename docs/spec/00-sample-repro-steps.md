# 仕様 00 付録：現行サンプル 不具合の再現手順

現行サンプル（main ブランチ c6423a1）の不具合を、手で再現するための手順書。
[取扱説明書（観察版）](00-sample-manual.md) の【不具合】と、【要確認】のうち画面で確かめられるものを対象にする。

- どの手順も、この文書のとおりにブラウザ（Chromium）で操作して、結果を確かめてある（2026-10-31）。札の出る順番を変えて、それぞれ2〜3回試した。
- 札の出る順番はランダムだが、出題する歌を絞り込んで、どの順番で出ても同じ結果になるようにしてある。
- 各項目の「直したら確かめること」は、修正のときに、周りの正常な動きを壊していないかを見るための項目。

## 準備

### どこで試すか

- 公開版 <https://karutatraining.github.io/> で試せる。主なファイルが main（c6423a1）と同じであることを照合済み（2026-10-31）。
- どの手順も最初に設定をリセットするので、普段使っている設定は消える。
- 手元で試す場合は、main を取り出したフォルダで次を実行し、<http://localhost:8000/> を開く。

```bash
python3 -m http.server 8000
```

### 毎回の初期化（設定のリセット）

各手順は、次の初期化から始める。

1. トップ画面 →「設定」
2. 「リセット」→ 確認で「OK」
3. 各手順の「設定」に書いた項目だけを変える
4. 「戻る (保存)」を押す（これを押さないと保存されない）

リセット直後の状態は次のとおり。

- 「決まり字を限定する」は ON の表示で、歌は1首も選ばれていない。この状態では100首すべてが対象になる。
- 各モードの設定は、設定画面の初期値（取扱説明書の各章の表のとおり）。

### 操作のこつ

- **歌を選ぶ**：「全解除」を押してから、「決まり字（個別）」の一覧で `#074 ：うか` のような行をタップする。
- **スライダー**：つまみをドラッグし、右に出る数値を見て合わせる。つまみを選んでから矢印キーを押すと、1ずつ動かせる。
  - 「出題枚数」と「同時枚数」は、書いた値ちょうどに合わせる。
  - 時間（ミリ秒）は目安なので、多少ずれてもよい。
- **トップ画面に戻る**：練習の画面にはトップへ戻るボタンがないので、ブラウザの「戻る」を使う。
- **札の見分け方**：取り札の左下にある小さな丸数字が歌番号。
- **盤面**（配置暗記・実践練習）：上3段が相手陣、下3段が自陣。

## 札流し

<a id="b-01"></a>
### B-01 決まり字変化 OFF が効かない（§2.5）

**設定**

- 歌：`#065 ：うら`、`#074 ：うか` の2首
- 札流し：「決まり字変化を考慮する」を OFF

**手順**

1. トップ →「札流し」
2. 1問目：出た札の決まり字を入力して Enter（74番なら `うか`、65番なら `うら`）。「OK」と出る。
3. 「次へ」を押す。
4. 2問目：同じように `うか` か `うら` を入力して Enter。

**本来の動き**：「OK」。変化 OFF なので、静的決まり字が正解。

**サンプルの動き**：「NG：正解は う」。代わりに `う` と入力すると「OK」になる。

**直したら確かめること**：「決まり字変化を考慮する」を ON に戻すと、2問目は `う` が正解になる。

<a id="b-02"></a>
### B-02 限定すると、選んだ歌だけで決まり字を計算する（§2.5）

**設定**

- 歌：`#074 ：うか` の1首だけ

**手順**

1. トップ →「札流し」。「残り札：1 枚」と表示される。
2. `うか` と入力して Enter。

**本来の動き**：「OK」。「うら」はまだ読まれていないので、「うか」の決まり字は「うか」のまま。

**サンプルの動き**：「NG：正解は う」。

**直したら確かめること**：歌を 65 と 74 の2首にすると、1問目は静的決まり字（うか／うら）、2問目は `う` が正解になる（決まり字変化 ON の正しい動き）。

## 札流し（複数枚）

<a id="b-03"></a>
### B-03 ローマ字を受け付けない（§3.3）

**設定**

- 歌：`#087 ：む`、`#018 ：す` の2首
- 札流し(複数枚同時)：同時枚数 2、出題枚数 2、出現時間 3000 前後（札を見やすくするため）
- 「ローマ字入力を許可」は ON のまま（リセット後の初期値）

**手順**

1. トップ →「複数枚・札認識」。む・す の2枚が出る。
2. `mu` と入力して Enter。
3. 入力欄を消し、`む` と入力して Enter。続けて `す` と入力して Enter。

**本来の動き**：手順2で `mu` が `む` と同じように受け付けられ、入力欄が空になる。

**サンプルの動き**：手順2では何も起きず、`mu` が入力欄に残る（文字が選択状態になるだけ）。手順3のかなは受け付けられ、「OK」になる。

**直したら確かめること**：「ローマ字入力を許可」を OFF にすると、`mu` は受け付けない。

<a id="b-04"></a>
### B-04 判定の後、次の問へ進めない（§3.6）

**設定**

- 歌：`#087 ：む`、`#018 ：す`、`#057 ：め`、`#022 ：ふ` の4首
- 札流し(複数枚同時)：同時枚数 2、出題枚数 4、出現時間 1000 前後、「回答後に自動で次へ進む」ON（待機時間は 500 のまま）

**手順**

1. トップ →「複数枚・札認識」
2. 出た2枚の決まり字（む・す・め・ふ のどれか）を、1枚ぶんずつ入力して Enter。2枚目で「OK」と出る。
3. そのまま3秒ほど待つ。続けて Enter を押す。
4. 「スキップ」を押す。

**本来の動き**：手順3で、待機時間（0.5秒）の後に次の問になる。「回答後に自動で次へ進む」が OFF なら、札流しと同じく「スキップ」が「次へ」に変わり、それを押すと進む。

**サンプルの動き**

- 手順3：何も起きない。同じ問のままで、進捗は「0 / 4」のまま。
- 手順4：判定の表示が「NG」に変わり、少し後に次の問が出る。進捗は「2 / 4」になる。
- 「回答後に自動で次へ進む」を OFF にしても同じ。ボタンは「スキップ」のまま変わらない。

**直したら確かめること**：判定の前に「スキップ」を押すと、今と同じく「NG」になって次の問へ進む（取扱説明書 §3.9）。

<a id="b-05"></a>
### B-05 決まり字変化の設定がない（§3.3、§3.7）

**手順**：トップ →「設定」→「札流し(複数枚同時)」欄を見る。

**本来の動き**：「決まり字変化」の ON／OFF がある（標準は OFF）。ON のときの正解は、取扱説明書 §3.7 のとおり。

**サンプルの動き**：項目がない（札の方向、ローマ字入力を許可、回答後に自動で次へ進む、待機時間、出題枚数、同時枚数、出現時間だけ）。2枚以上の問では、常に静的決まり字が正解になる。これは変化 OFF の動きと同じ。

<a id="b-06"></a>
### B-06 最後の1枚だけの問で、正解が常に1文字になる（§3.7）

**設定**

- 歌：`#023 ：つき`、`#074 ：うか`、`#039 ：あさじ` の3首
- 札流し(複数枚同時)：同時枚数 2、出題枚数 3、出現時間 1000 前後

**手順**

1. トップ →「複数枚・札認識」。2枚の問が出る。
2. 2枚の決まり字（つき／うか／あさじ のうち、出た2つ）を入力して「OK」にする。
3. 「スキップ」を押す（[B-04](#b-04) のため、これでしか進めない）。1枚だけの問が出る。
4. その札の決まり字（つき／うか／あさじ）を入力して Enter。
5. ブラウザの「戻る」でトップに戻り、手順1〜3をやり直す。今度は手順4で、最初の1文字（つ／う／あ）だけを入力して Enter。

**本来の動き**：手順4が「OK」、手順5が「NG」。「つく」「うら」「あさぼらけ…」はどれも出題されていないので、決まり字は変化しない。

**サンプルの動き**：手順4が「NG」、手順5が「OK」。1枚だけの問では、その1枚だけで決まり字を計算してしまうため。

**直したら確かめること**：2枚以上の問の正解（静的決まり字）が変わらないこと。

<a id="b-07"></a>
### B-07 端数の1枚の問で、前の問の札が表のまま残る（§3.8）

**設定**：[B-06](#b-06) と同じ。

**手順**：B-06 の手順1〜3。手順2は、札が伏せられて（白紙になって）から答える。

**本来の動き**：1枚の問では、その1枚だけが表示される。

**サンプルの動き**：大きく表示された今の問の札（出現時間の後は白紙）の横に、前の問の2枚が小さく表のまま残っている。

<a id="b-08"></a>
### B-08 終了したことが表示されない（§3.5）

**設定・手順**：[B-06](#b-06) の手順4の続き。

1. 3秒ほど待つ。
2. 「スキップ」を押す。

**本来の動き**：最後の問の判定の後、終了したことが分かる表示になる。進捗は「3 / 3」、残り札は「0 枚」。

**サンプルの動き**

- 手順1：何も起きない（[B-04](#b-04)）。
- 手順2：判定の表示が「NG」に変わる。最後の札は表のまま、入力欄の文字も残る。終了の表示はない。進捗は「2 / 3」、残り札は「1 枚」のまま。
- 割り切れる場合（[B-04](#b-04) の設定で2問とも答えて「スキップ」）：札の場所に、壊れた画像の表示（「札画像」）が出る。進捗は「2 / 4」、残り札は「2 枚」のまま。

<a id="b-09"></a>
### B-09 一覧の「並び替え」が歌番号の文字列順になる（§3.10、要確認）

**手順**：トップ →「複数枚・札認識」→「決まり字一覧を表示」→「並び替え」

**サンプルの動き**：「001: あきの」「010: これ」「100: もも」「011: わたのはらや」「012: あまつ」…の順になる。

**本来の動き**：【要確認】札流しの「読み上げ順」（出題済みの札を出題した順に並べる）に相当するものと思われる。

## 配置暗記

<a id="b-10"></a>
### B-10 「空札を除外する」が効かない（§4.7）

**設定**

- 歌：選ばない（リセット直後のまま）。100首が対象になり、66枚が場に出て、34枚は場に出ない。
- 配置暗記：出題モード「個別」、回答後に正解札を表示「する」（「空札を除外する」は ON のまま）

**手順**

1. トップ →「配置暗記」→「出題開始」
2. どのマスも選ばずに「回答」を押す。
3. 「誤答」なら、正解の札（場にある札）が1枚表になる。「次へ進む」を押して手順2に戻る。
4. 「正解」と出るまで繰り返す（たいてい数問以内）。

**本来の動き**：場にある札だけが出題されるので、何も選ばずに答えると必ず「誤答」になる。

**サンプルの動き**：数問のうちに「正解」と出て、表になる札がない。場にない札（空札）が出題されている。

**直したら確かめること**：「空札を除外する」が OFF なら、空札も出題される（今と同じ）。グループの出題で場に1枚もないグループをどうするかは、取扱説明書 §4.7 の要確認。

<a id="b-11"></a>
### B-11 「回答後に札の確認を許可」が使われない（§4.6）

**設定**

- 歌：`#087 ：む`、`#018 ：す` の2首（盤面の左上と右下に1枚ずつ置かれる）
- 配置暗記：出題モード「個別」、回答後に正解札を表示「しない」、回答後に札の確認を許可「する」

**手順**

1. トップ →「配置暗記」→「出題開始」
2. 何も選ばずに「回答」を押す（「誤答」になる）。
3. 盤面の札（左上か右下）をタップする。

**本来の動き**：確認を許可「する」なので、タップした札が表になる。

**サンプルの動き**：タップしても裏のまま。

**逆の組み合わせ**：回答後に正解札を表示「する」、確認を許可「しない」にして同じ手順を行う。回答で正解の札が表になった後、もう1枚の裏の札をタップすると表になる（本来はならない）。

<a id="b-12"></a>
### B-12 「回答後に自動で次へ進む」が使われない（§4.3、要確認）

**設定**

- 歌：`#087 ：む`、`#018 ：す` の2首
- 配置暗記：出題モード「個別」、回答後に自動で次へ進む ON（待機時間は 500 のまま）

**手順**：トップ →「配置暗記」→「出題開始」→「回答」→ 3秒ほど待つ。

**本来の動き**：待機時間の後に、次の出題になる。【要確認】配置暗記でこの設定を使う意図か。

**サンプルの動き**：同じ出題のまま。

<a id="b-13"></a>
### B-13 リセットしても裏のまま残る札がある（§4.5）

**設定**

- 歌：`#087 ：む` の1首だけ（1枚だけなので、毎回同じマス、自陣の右下に配られる）

**手順**

1. トップ →「配置暗記」。右下に札が1枚、表で置かれる。
2. その札をタップして裏にする。
3. 「リセット」を押す。
4. （別の確かめ方）「表示反転」を押して裏にしてから、「リセット」を押す。

**本来の動き**：リセットすると、配り直してすべて表になる。

**サンプルの動き**：裏のまま残る。普段は札がランダムに配られるので、同じマスに同じ札が配られたときだけ起きる。

## 実践練習

<a id="b-14"></a>
### B-14 盤面が保存されていないと動かない（§5.4）

**手順**（どちらか）

- ブラウザのシークレット（プライベート）ウィンドウで、<https://karutatraining.github.io/playing-karuta.html> を直接開く。
- トップ →「配置暗記」→「プレイ開始」→「プレイ終了」で配置暗記に戻った後、アドレス欄の `memorize-placement.html` を `playing-karuta.html` に書き換えて開く。

**サンプルの動き**：盤面に札が1枚も出ず、読み上げも始まらない。開発者ツールのコンソールに `Cannot read properties of null (reading 'noneCards')` と出る。

**本来の動き**：エラーで止まらない。盤面がないときにどうするかは【要確認】。

<a id="b-15"></a>
### B-15 決まり字を「これから読む札＋今の札」だけで計算する（§5.6）

**設定**

- 歌：`#074 ：うか` の1首だけ
- プレイ中モード：文字間隔 2000 前後（タップしやすくするため）

**手順**

1. トップ →「配置暗記」→「プレイ開始」
2. 読み上げで「う」が出たら、「か」が出る前に、場の札（右下の1枚）をタップする。
3. 判定を待つ。

**本来の動き**：「ズレ:x.xx 秒Earlier」。「うら」はまだ読まれていないので、決まる文字は「か」。

**サンプルの動き**：「正解:タイミングOK」。決まる文字が「う」として扱われている。

<a id="b-16"></a>
### B-16 読んでいる途中で「次へ進む」を押すと判定が狂う（§5.8）

**設定**

- 歌：`#031 ：あさぼらけあ`、`#064 ：あさぼらけう` の2首
- プレイ中モード：文字間隔 1000 前後（「回答後に自動で次へ進む」は OFF のまま）

**手順**

1. トップ →「配置暗記」→「プレイ開始」

## 要確認（画面で確かめられるもの）

<a id="q-01"></a>
### Q-01 カタカナを入力したときの理由の文言（§2.5）

**設定**：歌：`#087 ：む` の1首だけ

**手順**：トップ →「札流し」→ `ム` と入力して Enter

**サンプルの動き**：「NG：正解は む （ローマ字表記が仕様外）」

**確認したいこと**：理由の文言が、カタカナを入力したことと合っていない。

<a id="q-02"></a>
### Q-02 空欄のまま答えたとき（§2.5）

**設定**：[Q-01](#q-01) と同じ。

**手順**：トップ →「札流し」→ 何も入力せずに Enter

**サンプルの動き**：「NG：正解は む （ローマ字表記が仕様外）」

**確認したいこと**：空欄を不正解にするか、受け付けないか（複数枚では受け付けない）。理由の文言も合っていない。

<a id="q-03"></a>
### Q-03 「残り札」が何の数か（§2.8）

**設定**：歌：`#065 ：うら`、`#074 ：うか`、`#023 ：つき` の3首

**手順**：トップ →「札流し」→「スキップ」を3回押す。

**サンプルの動き**：残り札が「3 → 2 → 1 → 0」と減り、「お疲れさまでした！ 全問終了です。」と出る。限定しない場合は、100 から1ずつ減る。

**確認したいこと**：「まだ読まれていない札（100首 − 出題済み）」なら、限定しても 100 から減るべき。「残りの出題枚数」なら、出題枚数から減るべき。

<a id="q-04"></a>
### Q-04 複数枚の一覧に正誤が表示されない（§3.9、§3.10）

**設定**：[B-04](#b-04) と同じ（「回答後に自動で次へ進む」は OFF でもよい）。

**手順**

1. トップ →「複数枚・札認識」→「決まり字一覧を表示」を開いておく。
2. 1問目に正しく答えて「OK」にし、「スキップ」で次の問へ進む。
3. 2問目は答えずに「スキップ」を押す。

**サンプルの動き**：一覧の見た目は、最初から最後まで変わらない。正解した札も、スキップした札も、まだ出ていない札と同じ灰色の文字のまま。札流しの一覧にある「正解・初期」などの表示や色もない。

**補足**（コードで確認）：答えた札には内部で正誤の印を付けているが、印の名前が画面の飾り付けの定義と合っていないので、見た目に出ない。判定の前にスキップした札には、印も付かない。

**確認したいこと**：札流しの一覧のように、正誤を表示するのが意図か。表示する場合、スキップした札は誤答として表示するか（札流しでは誤答として記録される）。

<a id="q-05"></a>
### Q-05 1180×820 の画面で盤面の左端が切れる（§4.2）

**手順**：Chrome の開発者ツールでデバイス表示にし、画面の大きさを 1180×820 にして、トップ →「配置暗記」を開く。

**サンプルの動き**：盤面の左端が、約13ピクセル画面の外に出て切れる。

**確認したいこと**：どの画面の大きさに対応するか。

<a id="q-06"></a>
### Q-06 設定を一度も保存していないときの動き（§6.5）

**手順**

1. トップ →「設定」→「リセット」→「OK」
2. 「戻る (保存)」を押さずに、ブラウザの「戻る」でトップへ戻る。
3. 「札流し」で、「スキップ」を何回か押して札を見る。
4. ブラウザの「戻る」でトップに戻り、「複数枚・札認識」を開く。

**サンプルの動き**

- 手順3：札は毎回、正方向で表示される（設定画面の初期値は「ランダム」）。
- 手順4：札が6枚同時に出て、約5秒間、表で見える（設定画面の初期値は 5枚・500ミリ秒）。

**確認したいこと**：設定画面の初期値と、一度も保存していないときの動きの、どちらが意図した初期値か（ほかの項目は取扱説明書 §6.5 の表）。
