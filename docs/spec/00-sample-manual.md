# 仕様 00: 現行サンプル 取扱説明書（観察版）

現行サンプル（main ブランチ c6423a1）の遊び方とルールを、利用者向けの取扱説明書の形でまとめる。
実際にブラウザ（Chromium）で設定を変えながら操作し、コードと突き合わせて書いた。

この説明書は、私（実装担当）の理解を確認してもらうためのものである。解釈が違う箇所を指摘してもらい、直したものを新設計の仕様の元にする。

不具合を手で再現する手順は、[付録 不具合の再現手順](00-sample-repro-steps.md) にまとめた。

## 1. 共通

### 1.1 出題の範囲（決まり字を限定する）

設定画面の「決まり字を限定する（選択されたもののみ使用される）」で、出題する歌を絞り込める。

- 歌は「決まり字（グループ）」（例：あさ）と「決まり字（個別）」（例：#039 あさじ）の一覧から選ぶ。「全選択」「全解除」もある。
- ON で1首以上選んでいる → 選んだ歌だけを出題する。
- OFF、または ON でも1首も選んでいない → 100首すべてを出題の対象にする。
- 設定画面の初期値は ON。
- 【確認済み】限定は出題する歌を絞り込むだけで、決まり字の計算には影響しない。

### 1.2 決まり字と決まり字変化

決まり字の定義は [仕様 01](01-karuta-rules.md) のとおり。

- **静的決まり字**：100首すべてが残っているときの決まり字。いわゆる決まり字表の値。
- **決まり字変化**：このセッションで出題された（読まれた）歌を除いた残りの中で決まり字を計算し直すと、決まり字が短くなることがある。
  - 【確認済み】変化に影響するのは、実際に出題された歌だけ。限定しているかどうかは関係ない。

例：セッションの途中で「うら」が出題された後は、「うか」の決まり字は「う」になる。

### 1.3 答えの入力（かな・ローマ字）

札流しと札流し（複数枚）では、決まり字をキーボードで入力して答える。

- **かな**：ひらがなで入力する。カタカナや全角英字は受け付けない。
- **ローマ字**（設定で許可したとき）：
  - 大文字・小文字は区別しない。空白は無視する。
  - 半角英字のみ。全角英字（ｍｕ など）は受け付けない。
  - 母音 a i u e o、子音 k s t n h m y r w g z d b p と母音の組み合わせを受け付ける。
  - 揺れは shi / si（し）、chi / ti（ち）、tsu / tu（つ）、fu / hu（ふ）、ji / zi（じ）を受け付ける。
  - 「を」は wo、「は」は ha と入力する。例：かぜを = kazewo、いまは = imaha。
  - 44番「おおこ」は ooko と入力する。ouko は「おうこ」になるので不正解。
  - 撥音（ん）・促音（っ）・拗音（ゃゅょ）は扱わない（決まり字に現れない）。
- **かなとローマ字の混在**（うka など）は不正解。

【確認済み】上記の入力規則は意図どおり。

## 2. 札流し

### 2.1 概要

取り札を1枚ずつ見て、その札の決まり字を答える練習。

- 決まり字変化 OFF：静的決まり字を答える。取り札を見て決まり字を即答できるようにする練習。
- 決まり字変化 ON：その時点の決まり字を答える。どの歌がもう読まれたかを覚え、頭の中で決まり字を更新し続ける練習。

【確認済み】上記の2つの目的。

### 2.2 画面

- タイトル「競技かるた 札流し(決まり字変化)」
- 進捗「n / N」とバー。n は終わった問題数、N は出題枚数。
- 取り札の画像。下の句がひらがなで書かれ、左下に歌番号が小さな丸数字で入っている。
- 入力欄（「現時点の決まり字を入力（Enter可）」）、「答える」ボタン、「スキップ」ボタン
- 判定の表示（「OK」、または「NG：正解は ○○」）
- 「残り札：n 枚」
- 「リセット」ボタン
- 画面右の「決まり字一覧を表示」（開閉式）と「並び替え」ボタン

### 2.3 設定（設定画面の「札流し」欄）

| 項目 | 選択肢・範囲 | 設定画面の初期値 |
|---|---|---|
| 札の方向 | ランダム／正方向／逆さま | ランダム |
| ローマ字入力を許可 | ON／OFF | ON |
| 決まり字変化を考慮する | ON／OFF | ON |
| 回答後に自動で次へ進む | ON／OFF | OFF |
| 待機時間 | 1〜9999 ミリ秒 | 500 |
| 出題枚数 | 1〜100 枚 | 100 |

このほか、共通の「決まり字を限定する」（§1.1）が効く。

### 2.4 遊び方

1. 画面を開くと、すぐに1問目の札が表示される。
2. 札の決まり字を入力し、Enter キーか「答える」を押す。
3. 判定が表示される。判定後は入力欄がロックされ、答え直しはできない。
4. 次の札へ進む。
   - 自動で次へ進む ON：待機時間の後、自動で次の札になる。待っている間に「スキップ」を押すと、すぐ次へ進む。
   - 自動で次へ進む OFF：「スキップ」ボタンが「次へ」に変わるので、それを押す。
5. 出題枚数ぶん終わると「お疲れさまでした！ 全問終了です。」と表示され、札が消えて入力できなくなる。
   - 【不具合】出題の対象が出題枚数より多いと、終了後も「スキップ」が効く。押すたびに進捗が「4 / 3」「5 / 3」と増え、まだ出していない札が誤答として記録される（一覧に「誤答・初期」と出る）。対象を使い切ると止まる。操作して確認した例：5首に限定し、出題枚数 3。

### 2.5 判定のルール

- 入力が **その時点の決まり字と完全に一致** したときだけ正解。
- 決まり字変化 OFF なら、正解は静的決まり字。
  - 【不具合】サンプルでは OFF にしても効かず、決まり字変化した答えが正解になる（実際に操作して確認）。
- 決まり字変化 ON なら、正解は「100首 − このセッションで出題済みの歌」の中での決まり字。出題済みには、答えた札もスキップした札も含む。
  - 【不具合】サンプルでは、限定 ON のとき「選んだ歌 − 出題済み」の中で計算してしまう。例：「はなさ」「はるす」だけを選ぶと、最初の正解が「はなさ」ではなく「はな」になる。「うか」だけを選ぶと「う」になる。
- 決まり字が変化しているのに、変化前の決まり字（長い方）を答えると不正解。例：「うら」の後の「うか」に「うか」と答えると不正解。【確認済み】決まり字変化を追えていないため。
- 不正解のときは、理由が表示されることがある。
  - かなとローマ字の混在：「（かな＋ローマ字の混在は不可）」
  - ローマ字を許可していないのにローマ字を入力した、変換できないローマ字を入力した、カタカナ・全角英字を入力した：「（ローマ字表記が仕様外）」
  - 【不具合】カタカナを入力したときも、空欄のまま答えたときも、「ローマ字表記が仕様外」と表示される。文言が入力と合っていない。
  - 【確認済み】カタカナは受け付けないままでよい。表示する文言は、アプリ全体のメッセージの管理として検討する【要検討】（§8）。
- 【要確認】空欄のまま「答える」（Enter）を押すと、不正解として判定される。不正解にするか、受け付けない（何もしない）か。複数枚では受け付けない。
- 答えずに「スキップ」を押すと、誤答として記録して次の札へ進む。判定は表示しない。【確認済み】
  - 【変更】新しい版では、正解・誤答とは別の「スキップ」として記録する。実践練習と揃える（§5.8、§8）。

### 2.6 出題の範囲と順番

- 出題の対象は §1.1 のとおり。その中からランダムな順で、出題枚数ぶん出題する。対象が出題枚数より少なければ、対象を全部出題して終わる。【確認済み】
  - 例：出題枚数 4、対象 2枚 → 2枚出題して終わる。
  - 例：出題枚数 4、対象 6枚 → 6枚のうち4枚を出題して終わる。
- 1回のセッションで同じ札は1度しか出ない。

### 2.7 札の向き

- 正方向：常に正しい向き。
- 逆さま：常に180度回転して表示する。
- ランダム：1枚ごとに、正しい向きか逆さまかを半々の確率で決める。
- 設定を一度も保存していない場合は、正方向になる。

### 2.8 残り札

【確認済み】「残り札」は、残りの出題枚数を表す。このセッションで出題する枚数（出題枚数と、出題の対象の枚数の少ない方。§2.6）から始まり、1枚出題するごとに1減って、最後は 0 になる。

- 例：限定なし、出題枚数 3 → 3 → 2 → 1 → 0。
- 例：2首に限定、出題枚数 4 → 2 → 1 → 0。

【不具合】サンプルは、決まり字の計算に使っている残りの札の枚数（出題の対象 − 出題済み）を表示する。出題の対象が出題枚数より多いと、残りの出題枚数と合わない。操作して確認した例：限定なし、出題枚数 3 → 「100 → 99 → 98」と減り、97 で終わる。

### 2.9 決まり字一覧

「決まり字一覧を表示」を開くと、出題対象の歌の一覧が出る。各行は「#057：め」のような形式で、状態が付く。

| 状態 | 意味 |
|---|---|
| 未読・初期 | まだ出題されていない。決まり字は変化していない |
| 未読・変化中 | まだ出題されていない。今の時点で決まり字が変化している |
| 正解・初期／正解・変化 | 正解した。「変化」は出題時に決まり字が変化していたこと |
| 誤答・初期／誤答・変化 | 誤答（スキップを含む）。「変化」は同上。【変更】新しい版では、スキップした札は誤答と分けて表示する（§2.5）。表示の文言は未定 |

状態は、判定の直後ではなく、次の札に進んだときに更新される（操作して確認）。

並び順は「並び替え」ボタンで切り替わる。

- 決まり字順（初期）：「むすめふさほせ」「うつしもゆ」「いちひき」「はやよか」「みたこ」「おわな」「あ」の、決まり字表の順。
- 読み上げ順：出題済みの札だけを、出題した順に並べる。

### 2.10 リセット

「リセット」を押すと、新しい順番で最初からやり直す。成績もすべて消える。

### 2.11 この章の【不具合】一覧

1. 決まり字変化 OFF が効かない（§2.5）
2. 限定 ON のとき、決まり字を選んだ歌だけで計算する（§2.5）
3. カタカナや空欄で答えたときの理由の文言が、入力と合っていない（§2.5）
4. 「残り札」が、残りの出題枚数にならない（§2.8）
5. 終了後も「スキップ」が効き、出していない札が誤答として記録される（§2.4）

## 3. 札流し（複数枚）

### 3.1 概要

複数の取り札を同時に一定時間だけ見せ、伏せた後で、全部の札の決まり字を答える練習。

### 3.2 画面

- タイトル「競技かるた 札流し(複数)」
- 進捗「n / N」とバー。n は出題済みの **札の枚数**、N は出題枚数（問題の数ではない）。
- 札を並べる枠（3列×2段）
- 入力欄、「答える」、「スキップ」
- 判定の表示（初期は「未開始」、判定後は「OK」か「NG」。正解は表示されない）
- 「残り札：n 枚」：残りの出題枚数（札流しと同じ意味。§2.8）
- 「リセット」、「決まり字一覧を表示」と「並び替え」

### 3.3 設定（設定画面の「札流し(複数枚同時)」欄）

| 項目 | 選択肢・範囲 | 設定画面の初期値 | 備考 |
|---|---|---|---|
| 札の方向 | ランダム／正方向／逆さま | ランダム | 1問の中の札はすべて同じ向き |
| ローマ字入力を許可 | ON／OFF | ON | 【不具合】サンプルでは常にローマ字を受け付けない |
| 回答後に自動で次へ進む | ON／OFF | OFF | 【不具合】サンプルでは ON にしても次へ進まない（§3.6） |
| 待機時間 | 1〜9999 ミリ秒 | 500 | |
| 出題枚数 | 1〜100 枚 | 100 | 出題する札の総枚数 |
| 同時枚数 | 2〜6 枚 | 5 | 1問で同時に出す枚数 |
| 出現時間 | 1〜9999 ミリ秒 | 500 | 札を表で見せる時間 |
| 決まり字変化 | ON／OFF（標準 OFF） | — | 【確認済み】意図としてある設定。サンプルには設定項目がない |

設定を一度も保存していない場合、サンプルは同時枚数6枚、出現時間5秒、ローマ字なし、向きはランダムで動く。

### 3.4 札の並べ方

同時枚数ぶんの札を、3列×2段の枠に次の順で置く（見た目の位置）。

| 上段左：6枚目 | 上段中：4枚目 | 上段右：3枚目 |
|---|---|---|
| **下段左：5枚目** | **下段中：2枚目** | **下段右：1枚目** |

- 枚数が少ないときは、空いた位置は空欄のまま残る。例：2枚なら下段右と下段中だけに置く。
- 逆さまのときは、枠ごと180度回転する。並び順の見た目は同じ。
- 【要確認】この並び順に意味があるか（何かの練習を想定した配置か）。

### 3.5 遊び方

1. 問が始まると、札が出現時間のあいだ表で表示される。その後、札は伏せられる（白紙の札になり、位置は残る）。伏せられる前から答え始めてもよい。
2. 決まり字を **1枚ぶんずつ** 入力して Enter（または「答える」）を押す。
   - 受け付けると入力欄が空になり、次の入力を待つ。
   - 空欄、かなとローマ字の混在、ローマ字（§3.3 の不具合のため）は受け付けられず、入力欄の文字が選択状態になるだけ。
3. 同時枚数ぶん入力すると、まとめて判定される。
   - 1問のすべての札の決まり字が、ちょうど1回ずつ入力されていれば「OK」。それ以外は「NG」。
   - 答える順番は問わない。同じ答えを2回入力すると NG。
4. 判定後、伏せていた札が表に戻る。
5. 次の問へ進む（§3.6）。
6. 出題枚数ぶん終わると、終了する。
   - 【不具合】終了したことが画面に表示されない（「終了」は画面に出ない部品に書き込まれる）。進捗と残り札も最後の問のぶん更新されない（例：3枚出題して「2 / 3」「残り札：1 枚」のまま）。操作して確認した動き：
     - 最後の問の判定の後も何も起きず、「スキップ」を押して初めて終わる（§3.6 の不具合のため）。このとき判定の表示は「NG」に変わる。
     - 割り切れるとき：札の場所に壊れた画像の表示（「札画像」）が出る。
     - 端数の1枚の問で終わるとき：最後の札が表のまま残り、入力欄の文字も残る。

### 3.6 次の問へ進む操作

【不具合（要確認）】サンプルでは、判定後に次の問へ進む手段がない。

- 「回答後に自動で次へ進む」が ON でも OFF でも、判定後は何も起きない（2秒待っても同じ問のまま。Enter を押しても進まない）。
- 進むには「スキップ」を押す。このとき判定の表示が「NG」に変わり、待機時間の後に次の問が出る。ただし内部の正誤の記録は、本来の判定のまま残る（一覧には表示されない。§3.10）。

札流しと同じく「自動 ON なら待機時間後に次へ、OFF なら『次へ』ボタン」が意図と思われる。

### 3.7 判定に使う決まり字

【確認済み】の意図：

- 決まり字変化 OFF（標準）：正解は静的決まり字。
- 決まり字変化 ON：正解は、**その問が出た時点** の決まり字。つまり「100首 − それより前の問で出題済みの歌」の中で計算する。
  - 同じ問の札どうしでは決まり字を変化させない。答える順番によって正解が変わることもない。
  - 例：「うか」と「うら」が同じ問に出たら、正解は「うか」と「うら」（順不同）。
  - 例：前の問で「うら」が出ていたら、後の問の「うか」の正解は「う」。

サンプルの実際の動作：

- 2枚以上の問では、常に静的決まり字が正解になる。前の問で出題済みの歌も考慮しない（操作して確認：前の問で「うら」が出た後の問でも、「うか」が正解）。これは決まり字変化 OFF の意図とは一致する。
- 【不具合】最後の問が1枚だけになった場合（§3.8）は、その1枚だけで決まり字を計算するため、常に1文字が正解になる（操作して確認：「つく」が出題されていなくても、「つき」の正解が「つ」になる）。

### 3.8 端数の問

出題枚数が同時枚数で割り切れないときは、最後の問だけ残りの枚数で出る。例：出題枚数6、同時枚数5 → 5枚の問、1枚の問。

- 1枚だけの問は、1回の入力ですぐ判定される。空欄などの無効な入力でも、その場で NG になる。
- 【不具合】1枚だけの問では、前の問の札が画面から消えずに、小さく表のまま残る。今の問の札は大きく表示され、出現時間の後に伏せられる（操作して確認）。

### 3.9 スキップ

- 判定前に「スキップ」を押すと、判定の表示が「NG」になり、待機時間の後に次の問が出る。
- 【不具合】このとき、スキップした札には正誤の記録が残らない（コードで確認。一覧に正誤が表示されないため、画面では見えない）。【確認済み】札流しと同じ扱いにするのが意図。新しい版では「スキップ」として記録する（§2.5、§3.10）。

### 3.10 決まり字一覧

【確認済み】の意図：札流しの一覧（§2.9）と同じにする。

- 出題の対象の歌だけを表示する（札流しと同じ）。
- 各行に、正誤と、決まり字変化の有無を表示する（札流しの「正解・初期」「誤答・変化」など）。スキップした札は、札流しと同じく「スキップ」として扱う（§2.5）。
- 決まり字変化の有無は、**問（グループ）単位** で決める。その問が出た時点で決まり字が変化していたかどうかで、同じ問の中で答えている途中に変化することはない（§3.7 と同じ考え方）。
- 並び順は「並び替え」で、次の2つを切り替える。
  - 決まり字順（初期）：「むすめふさほせ」…「あ」の、決まり字表の順（§2.9 と同じ）。
  - 出題順：出題済みの札を、出題した順に並べる。同じ問の札は、§3.4 の1枚目を先頭に、2枚目、3枚目…6枚目の順に並べる。

サンプルの実際の動作：

- 各行は「001: あきの」の形式。
- 【不具合】限定していても、常に100首すべてを表示する。操作して確認した例：「む」「す」の2首に限定すると、札流しの一覧は2行、複数枚の一覧は100行。
- 【不具合】出題済みの札にも正誤が表示されない。一覧の見た目は、最初から最後まで変わらない（操作して確認）。
  - 内部では答えた札に正誤の印を付けているが、印の名前が画面の飾り付けの定義と合っていないので、見た目に出ない（コードで確認）。
  - 判定の前にスキップした札には、印も付かない（§3.9）。
- 【不具合】初期の並びが決まり字の五十音順になっている（あい、あきか、あきの…）。
- 【不具合】「並び替え」を押すと、歌番号を **文字列として** 並べた順（1, 10, 100, 11, 12, …）になる。

### 3.11 この章の【不具合】一覧

1. ローマ字入力を許可しても、ローマ字を受け付けない（§3.3）
2. 判定後に次の問へ進む手段がなく、スキップすると判定の表示が NG に変わる（§3.6）
3. 決まり字変化の設定がない（§3.3、§3.7）
4. 最後の1枚だけの問で、正解が常に1文字になる（§3.7）
5. 終了したことが画面に表示されず、進捗と残り札も最後の問のぶん更新されない（§3.5）
6. 一覧の並び替えが歌番号の文字列順になり、初期の並びも決まり字表の順でない（§3.10）
7. 端数の1枚の問で、前の問の札が表のまま残る（§3.8）
8. 一覧に正誤と決まり字変化の有無が表示されず、スキップした札は記録もされない（§3.9、§3.10）
9. 一覧に、出題の対象でない歌も表示される（§3.10）

## 4. 配置暗記

### 4.1 概要

盤面に並べた札の位置を覚える練習。出題された決まり字の札がどこにあるかを、盤面のマスを選んで答える。

### 4.2 画面

- 左に盤面（畳の背景、6段×11列のマス）。
  - 上の3段は相手陣。札は逆さまに表示される。
  - 下の3段は自陣。札は正しい向きで表示される。
- 右上に「決まり字（グループ）」と「決まり字（個別）」の一覧。
- 右下にボタン。出題前は「リセット」「表示反転」「出題開始」「プレイ開始」。出題中は「終了」「回答」「次へ進む」。
- 出題中は、出題（決まり字）と判定（「正解」は緑、「誤答」は赤）が表示される。
- 【要検討】1180×820 の画面では、盤面の左端が画面からはみ出して切れる。どの機器・画面の大きさに、どこまで対応するかという広い論点として扱う（§8）。

### 4.3 設定（設定画面の「配置暗記」欄）

| 項目 | 選択肢・範囲 | 設定画面の初期値 | 備考 |
|---|---|---|---|
| 出題モード | 混合／個別／グループ | グループ | §4.7 |
| 空札を除外する | ON／OFF | ON | 【不具合】効かない。場にない札も出題される |
| 回答後に正解札を表示 | する／しない／正答時のみ／誤答時のみ | 正答時のみ | §4.6 |
| 回答後に札の確認を許可 | する／しない／正答時のみ／誤答時のみ | 正答時のみ | 【不具合】この設定は使われず、「回答後に正解札を表示」と同じ値で動く |
| 回答後に自動で次へ進む | ON／OFF | OFF | 【不具合】設定はあるが使われていない。【確認済み】ON なら、回答の後、待機時間が経つと次の出題になるのが意図 |
| 待機時間 | 1〜9999 ミリ秒 | 500 | 【不具合】同上 |

このほか、共通の「決まり字を限定する」（§1.1）と、設定画面の「札の配置設定」（使うマス）が効く。

### 4.4 札の配り方

1. 出題の対象（§1.1）からランダムに選び、使えるマスの数まで配る。対象の方が少なければ全部配る。
2. 半分（端数は切り捨て）を相手陣、残りを自陣に置く。例：7首なら相手陣3枚、自陣4枚。
3. 相手陣は画面の一番上の段の左から、自陣は一番下の段の右から順に詰めて置く。つまり、どちらも自分から見て下段から並べる。使わないマスは飛ばす。
   - 例：66マスすべて使い、10首に限定した場合 → 一番上の段の左に5枚、一番下の段の右に5枚。
   - 例：66マスすべて使い、100首の場合 → 66マスすべてが埋まる（33枚＋33枚）。
   - 例：各陣25マスの配置（中央に通路がある形）の場合 → 25枚＋25枚。
4. 画面を開くたびに配り直す（実践練習から戻ったときを除く。§4.8）。

### 4.5 出題前（覚える時間）の操作

- 盤面の札をタップすると裏返る。もう一度タップすると表に戻る。裏返した札は、個別の一覧で選択表示になる。
- 個別の一覧の行をタップすると、その札が裏返る。
- グループの一覧の行をタップすると、そのグループの札がまとめて裏返る。そのグループに含まれる小さいグループの行も選択表示になる（例：「あ」を選ぶと「あき」「あさ」なども選択表示）。
- 「表示反転」を押すと、盤面全体の表と裏が入れ替わる。それまで裏返していた札だけが表になる。
- 「リセット」を押すと、新しく配り直し、すべて表にする。
  - 【不具合】表示反転の後などにリセットすると、たまたま同じマスに同じ札が配られた場合、その札が裏のまま残る。
- 「プレイ開始」を押すと、今の盤面のまま実践練習に進む（§5）。

### 4.6 出題の流れ

1. 「出題開始」を押すと、盤面の札がすべて裏になり、最初の出題（決まり字）が表示される。一覧は操作できなくなる（薄く表示される）。「表示反転」も使えない。
2. 出題された札があると思うマスをタップする。タップしたマスは白い札になる。もう一度タップすると取り消せる。
3. 「回答」を押すと判定される。選んだマスが正解のマスと **完全に一致** すれば「正解」、それ以外は「誤答」。
   - 個別の出題：その札がある1マスが正解。その札が場にない（空札）なら、何も選ばずに「回答」を押すのが正解。
   - グループの出題：静的決まり字がその文字で始まる札のうち、場にあるもの **すべて** のマスが正解。例：「な」なら、「な」で始まる札が場に5枚あれば5枚とも選ぶ。
4. 「回答後に正解札を表示」の設定に従い、正解の札が表になる。
   - する：正解でも誤答でも表にする。しない：表にしない。正答時のみ／誤答時のみ：その場合だけ表にする。
5. 「回答後に札の確認を許可」が有効なとき、盤面の札をタップして表裏を切り替えたり、一覧を操作したりして確認できる。
   - 【不具合】サンプルでは、この可否が「回答後に正解札を表示」の設定で決まる。例：正解札の表示を「しない」、確認を「する」にしても、確認できない。
6. 「次へ進む」で次の出題になる。判定前でも押せて、その場合は判定せずに次へ進む。
   - 【要確認】判定前に次へ進んだ問を、「スキップ」として記録するか。札流しと実践練習は「スキップ」の状態を持つ（§8）。サンプルの配置暗記には、結果を残す仕組みがない（コードで確認）。
7. 全部出題した後に「次へ進む」を押すと、「出題はすべて消費しました。」と表示され、出題前の状態（すべて表）に戻る。
8. 「終了」を押すと、いつでも出題前の状態に戻る。

### 4.7 出題の範囲と順番

- 出題モード
  - グループ：出題の対象の歌を含む決まり字グループを、すべて出題する。「あ」と「あさ」のように重なるグループも、それぞれ1問として出る。
  - 個別：出題の対象の歌を、すべて出題する。
  - 混合：グループと個別をすべて混ぜて出題する。
- どれもランダムな順で、1回ずつ出題する。
- 場にない札（空札）も出題される。グループの出題では、場に1枚もないグループも出る（その場合は何も選ばないのが正解）。
  - 【不具合】「空札を除外する」が効かないため。
  - 【要確認】「空札を除外する」が ON のとき、グループの出題でも「場に1枚もないグループ」を除くのが意図か。

### 4.8 実践練習との行き来

- 「プレイ開始」を押すと、今の盤面のまま実践練習に進む。
- 実践練習の「プレイ終了」で戻ると、同じ盤面に戻る。実践練習で取り除かれた札も元の位置に戻る。
- その後に画面を再読み込みすると、新しく配り直す。

### 4.9 この章の【不具合】一覧

1. 「空札を除外する」が効かない（§4.7）
2. 「回答後に札の確認を許可」が使われず、「回答後に正解札を表示」の値で動く（§4.6）
3. 「回答後に自動で次へ進む」「待機時間」が使われていない（§4.3）
4. リセット後に裏のまま残る札がある（§4.5）

## 5. 実践練習

### 5.1 概要

配置暗記の盤面を使い、決まり字が1文字ずつ表示されるのを見て、その札を取る（タップする）練習。札の位置を覚えているかと、取るタイミングを練習する。

【確認済み】配置暗記の実践なので、違う札に触れたら不正解とする（公式戦のお手つきの規則とは別）。

### 5.2 画面

- 左に盤面。札はすべて表で、配置暗記と同じ並び。
- 右に決まり字の一覧（グループ・個別）。プレイ中は操作しない。
- 出題の表示（決まり字が1文字ずつ現れる）と、判定の表示。
- ボタンは「次へ進む」「プレイ終了」。

### 5.3 設定（設定画面の「プレイ中モード」欄）

| 項目 | 選択肢・範囲 | 設定画面の初期値 | 備考 |
|---|---|---|---|
| 空札を除外する | ON／OFF | ON | ON：場にある札だけを読む。OFF：場にない札（空札）も読む |
| 文字間隔 | 1〜9999 ミリ秒 | 500 | 決まり字を1文字表示する間隔 |
| 回答後に自動で次へ進む | ON／OFF | OFF | |
| 待機時間 | 1〜9999 ミリ秒 | 500 | 判定を表示してから次の出題までの時間 |

このほか、共通の「決まり字を限定する」（§1.1）が効く。設定を一度も保存していない場合、サンプルは文字間隔1秒、待機8秒、空札も読む、で動く。

### 5.4 始め方

- 配置暗記で「プレイ開始」を押す。画面を開くとすぐに1問目が始まる。
- 【不具合】配置暗記を経ずにこの画面を直接開くと（盤面が保存されていないと）、盤面が表示されず、エラーで動かない。
- 【確認済み】盤面がないときは、そのことを伝えるメッセージと、配置暗記の画面へ移るボタンを表示する。メッセージの文言は未定。

### 5.5 1問の流れ

1. 出題する歌の静的決まり字が、文字間隔ごとに1文字ずつ表示される（例：「あさぼらけあ」なら、あ、さ、ぼ、ら、け、あ）。決まり字変化で短くなっていても、静的決まり字の全部の文字を表示する。
2. 取ると思った札をタップする。1問につき、最初の1回のタップだけが有効。
3. 最後の文字を表示してから、文字間隔ぶん後に判定が表示される（§5.6）。
4. 読まれた札は、正誤に関係なく場から取り除かれる。
5. 次の出題へ進む。
   - 自動で次へ進む ON：待機時間の後に自動で次の出題になる。
   - 自動で次へ進む OFF：「次へ進む」を押す。
6. 全部読み終わった後に「次へ進む」を押す（自動のときは待機時間が経つ）と、「終了」と表示される。

### 5.6 判定

「決まる文字」を、その時点の決まり字の最後の文字とする。例：決まり字が「うか」なら「か」、変化して「う」になっていれば「う」。

| 状況 | 表示 |
|---|---|
| 場にある札が読まれ、決まる文字が表示されてから文字間隔の時間内に、その札をタップした | 正解:タイミングOK |
| 同上で、決まる文字が表示される前にタップした | ズレ:x.xx 秒Earlier（決まる文字の表示より何秒早かったか） |
| 同上で、時間内より後にタップした | ズレ:x.xx 秒Over（時間内の終わりから何秒遅れたか） |
| 場にある札が読まれ、違う札をタップした | 不正解: 誤札 |
| 場にある札が読まれ、どの札もタップしなかった | 不正解:時間Over |
| 空札が読まれ、どの札もタップしなかった | 正解:空札 |
| 空札が読まれ、どれかの札をタップした | 不正解: 誤札 |

操作して確認した例（文字間隔1.5秒）：決まり字が2文字の札を1文字目でタップすると「ズレ:1.34 秒Earlier」。決まり字が1文字の札を1文字目でタップすると「正解:タイミングOK」。

決まる文字を決める決まり字は、【確認済み】「100首 − このセッションで読まれた歌」の中で計算する。限定しているかどうか、空札を除外しているかどうかは関係ない。

- 【不具合】サンプルは「これから読む予定の札＋今の札」の中で計算する。このため、限定や空札除外で読まない札が、まだ読まれていないのに計算から外れる。操作して確認した例：
  - 「うか」だけに限定し、「うら」も場にある（読まれていない）場合 → 1文字目でタップして「正解:タイミングOK」になる。本来は「うか」の2文字目が決まる文字。
  - 空札を除外し、場に「あ」で始まる札が「あさぼらけう」「あさぼらけあ」だけの場合 → 「あさぼらけう」の後の「あさぼらけあ」は1文字目で決まる。本来は「あさじ」などがまだ読まれていないので、「あさぼ」の3文字目が決まる文字。

### 5.7 出題の範囲と順番

- 出題の対象は §1.1 のとおり。空札を除外する ON なら、そのうち場にある札だけを読む。OFF なら、場にない札も空札として読む。
- ランダムな順で、全部1回ずつ読む。

### 5.8 読んでいる途中の「次へ進む」

【不具合】決まり字を表示している途中で「次へ進む」を押すと、前の出題の時間管理が止まらずに残る。

- 前の出題の判定が、新しい出題の札に対して行われる。操作して確認した例：途中で次へ進むと、すぐに新しい札が「不正解:時間Over」と表示されて場から消え、その後同じ札が「正解:空札」と表示される。
- 途中で飛ばした札は判定されず、場に残る。

【確認済み】の意図：1問目と2問目を完全に切り離す。

- 「次へ進む」を押したら、1問目に関する処理（文字の表示、時間の管理、判定）と状態を、すべて終了させる。
- 1問目は「スキップ」として記録する（札流しと揃える。§2.5、§8）。
- 1問目の札は、普通に1問が終わったときと同じく、場から取り除く（§5.5 の4）。
- 1問目が完全に終わった状態になってから、2問目を始める。1問目の何かが2問目に影響することはない。

なお、サンプルの実践練習には、結果を残す仕組み（一覧や集計）がなく、判定をその場で表示するだけ（コードで確認）。記録した結果をどう見せるかは未定。

### 5.9 プレイ終了

「プレイ終了」を押すと配置暗記に戻る。盤面は元の並びに戻る（§4.8）。

### 5.10 この章の【不具合】一覧

1. 盤面が保存されていないと動かない（§5.4）
2. 決まり字を「これから読む予定の札＋今の札」だけで計算する（§5.6）
3. 読んでいる途中で「次へ進む」を押すと判定が狂う（§5.8）

## 6. 設定画面

### 6.1 画面

トップ画面の「設定」から開く。上から順に次の要素がある。

- 「戻る (保存)」ボタン
- 見出し「各種設定」と「リセット」ボタン
- 「決まり字を限定する(選択されたもののみ使用される)」のチェック
- 「決まり字（グループ）」の一覧と「決まり字（個別）」の一覧（「#087 ：む」の形式）、「全選択」「全解除」ボタン
- モードごとの設定欄：「札流し」「札流し(複数枚同時)」「配置暗記」「プレイ中モード」（内容は第2〜5章の表のとおり）
- 「設定 (札の配置)」：6段×11列のチェック欄と、「デバッグ用 札の配置設定の配列」のテキスト欄

### 6.2 歌の選び方

- 個別の一覧の行をタップすると、その歌を選ぶ／外す。
- グループの一覧の行をタップすると、そのグループの歌をまとめて選ぶ。すでに全部選ばれていれば、まとめて外す。
- グループの行は、含まれる歌が全部選ばれているときだけ選択表示になる。
  - 例：「あさ」を選ぶと、あさじ・あさぼらけあ・あさぼらけうの3首が選ばれ、「あさ」と「あさぼ」の行が選択表示になる。その後あさじを外すと、「あさ」の選択表示は消え、「あさぼ」は残る。
- 「全選択」で100首すべて、「全解除」で0首になる。
- 選んだ歌と「決まり字を限定する」は、すべてのモードで共通。

### 6.3 札の配置設定

- 6段×11列のチェック欄が、配置暗記・実践練習の盤面の各マスに対応する。上3段が相手陣、下3段が自陣。
- チェックありのマスに札を置き、チェックなしのマスは使わない。
- 初期値はすべてのマスを使う（66マス）。
- 下のテキスト欄に、使わないマスを `true` とした配列が表示される（デバッグ用）。
- 【要確認】サンプルのデータには、各陣25マスで中央に通路がある配置が用意されているが、どこからも使われていない。

### 6.4 保存とリセット

- 「戻る (保存)」を押したときだけ設定を保存し、トップ画面に戻る。ブラウザの「戻る」などで画面を離れると、変更は保存されない。
- 「リセット」を押すと「設定をすべてリセットしますか？」と確認され、OK なら保存済みの設定をすべて消して初期値に戻す。「戻る (保存)」を押さなくても、この時点で保存済みの設定は消えている（コードで確認）。
- 【変更】新しい版では、次のようにする。
  - 「リセット」は、画面の設定を初期値に戻すだけにする。保存はしない。
  - 「戻る」と「保存」を分け、保存だけをするボタンを作る。保存せずに戻ったときの扱いは未定。
  - トップに戻るボタンは、設定画面に限らず、どの画面にも表示する（§7.1）。
- 【不具合】「決まり字を限定する」を OFF にして保存しても、次に設定画面を開くと ON の表示に戻る。そのまま「戻る (保存)」を押すと ON で保存される。各モードは、保存された OFF のとおりに動く。

### 6.5 設定を一度も保存していないときの動作

設定画面に表示される初期値と、設定を一度も保存していないときの各モードの動作が異なる項目がある。

「一度も保存していないとき」とは、初めて使うときや、ブラウザのデータを消したとき。サンプルでは、設定画面で「リセット」→「OK」としたときも、保存済みの設定が消えてこの状態になる（§6.4）。

| 項目 | 設定画面の初期値 | 一度も保存していないときの動作 |
|---|---|---|
| 札流し：札の方向 | ランダム | 正方向 |
| 複数枚：同時枚数 | 5枚 | 6枚 |
| 複数枚：出現時間 | 500ミリ秒 | 5秒 |
| 複数枚：ローマ字入力 | 許可 | 許可しない |
| 実践練習：文字間隔 | 500ミリ秒 | 1秒 |
| 実践練習：待機時間 | 500ミリ秒 | 8秒 |
| 実践練習：空札を除外する | ON | OFF（空札も読む） |

【要確認】どちらが意図した初期値か。

## 7. トップ画面、報告・共有、リンク集

### 7.1 トップ画面

- タイトルは「競技かるた トレーニング」。
- ボタンは「札流し」「複数枚・札認識」「配置暗記」「設定」「報告・共有」「リンク集」の6つ。
- 実践練習へは、トップ画面からではなく配置暗記の「プレイ開始」から入る。
- トップ画面に戻るボタンは、設定画面の「戻る (保存)」だけ。ほかの画面からは、ブラウザの「戻る」で戻る（コードで確認）。
  - 【変更】新しい版では、どの画面にもトップに戻るボタンを表示する。

### 7.2 報告・共有

「報告・情報共有・連絡フォーム」から、開発者に報告や連絡を送る。実際の送信はしておらず、以下はコードから確認した内容。

- 入力項目
  - ユーザー名（必須。「ニックネーム・名前など(仮でOK)」）
  - 要件（必須。「バグ報告/意見/質問など」）
  - 内容（必須）
  - 画像ファイル（任意）
  - 動画ファイル（任意）
- 注意書きとして「ファイル(サイズ制限あり/1回の送信に30秒以上かかる場合エラー?)」「ファイル送信ができない場合は、ファイル共有のURLでお送りいただけると幸いです」と表示される。
- 「送信(すぐ送信)」を押すと、Google Apps Script のウェブアプリ1か所に、次の順で送る。途中で失敗したら、そこで止めてエラーを表示する。
  1. 内容
  2. ユーザー名と要件（「Responses」という表に1行として）
  3. 画像（選んだ場合）
  4. 動画（選んだ場合）
- 結果は画面下にログとして表示される。
- 【不具合】画像・動画の送信に失敗したときのエラーメッセージが文字化けしている。【確認済み】新しい版では、正しい文言で書くだけでよい。
- 【不具合】1回の報告が、送信先で1件にまとまらない。
  - 上の1〜4は、それぞれ別々の送信で、送り先の種類も違う。内容は「文書（doc）」として、ユーザー名と要件は「表（sheet）」の1行として、画像と動画は「ファイル（upload）」として送る。
  - どの送信にも、同じ報告だと分かる共通の印（受付番号など）が付いていない。このため受け取った側では、どの内容がどのユーザー名・要件のものか、どの画像がどの報告のものかを、送られてきた順番などから推測するしかない（送信先の Google Apps Script のプログラムはこのリポジトリになく、受け取った側でどう保存されるかは確かめられない）。
  - 例：1の内容の送信が成功し、2で失敗すると、名前のない内容だけが届く。
  - 【確認済み】1回の報告（ユーザー名・要件・内容・画像・動画）を、受け取った側で1件として扱えるようにする。方法は次のどちらか。どちらにするかは【要検討】（§8）。どちらでも、送信先のプログラムも変える必要がある。
    - 各送信に、同じ報告だと分かる印、または採番した番号を付ける。
    - そもそも1回の送信で送る。

### 7.3 リンク集

- 見出し「競技かるた おすすめリンク集」。練習・大会情報・メーカー・音源・読み物などのリンクが22件ある。
- 分類タブ（すべて／公式／練習/ツール／メーカー/ショップ／音源／読み物／YouTube／実写／アニメ）と検索欄で絞り込める。例：「公式」で1件、「天狗堂」で検索すると4件。
- リンクは新しいタブで開く。

## 8. 新しい版の全体に関わること

個々の章への回答のうち、新しい版の全体に関わるものをまとめる。

### 8.1 決まったこと

- **スキップの状態**：答えずに先へ進んだ問を、正解・誤答とは別の「スキップ」として記録する。札流し（§2.5）、札流し（複数枚）（§3.9）、実践練習（§5.8）。一覧などでの見せ方は未定。配置暗記は【要確認】（§4.6）。
- **トップに戻るボタン**：どの画面にも表示する（§7.1）。
- **設定画面のボタン**：「リセット」は初期値に戻すだけで保存しない。「戻る」と「保存」を分ける（§6.4）。

### 8.2 要検討

- **メッセージの管理**：判定の理由、エラー、案内などの文言は、1か所ずつ決めるのではなく、アプリ全体を通した統合的な観点で管理する。きっかけ：§2.5 の理由の文言。関係する箇所：§5.4 の盤面がないときのメッセージ、§7.2 の文字化け。
- **機器・画面の大きさへの対応**：どれくらいの粒度で分け、どこまで対応するか。きっかけ：§4.2（1180×820 で盤面の左端が切れる）。
- **報告の送信のまとめ方**：同じ報告だと分かる印や番号を付けるか、1回で送るか（§7.2）。
