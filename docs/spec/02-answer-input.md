# 仕様 02: 答えの入力と判定

札流しと札流し（複数枚）では、決まり字をキーボードで入力して答える。答えは1行に、区切りの文字で分けて入力する。札流しは1つ、複数枚は問の札の枚数ぶんの答えを入れる。

この文書は、入力を答えに分けること、答えをひらがなに直すこと（かな・ローマ字）、答えが正解かどうかの判定を定める。2つのモードは、同じ規則を使う。

スキップ、次の問へ進む操作などの進行と、判定の表示は、各モードの仕様で定める。正解の決まり字の求め方は、[仕様 01](01-karuta-rules.md) に従う。

根拠：

- 取扱説明書 §1.3（入力の規則。ユーザー確認済み）、§2.5（札流しの判定）、§3.5・§3.7・§3.8（複数枚の判定）、§8.1（空欄）
- 不具合 B-03・B-22・B-25 の本来の動き
- ユーザーの決定（2026-10-31）：1行に区切って入力する方式、空白の扱い、かなに直せない理由の分け方、札ごとの正誤（§11）
- 取扱説明書に書いていない細部は、サンプルを動かして確かめた（§9）

## 1. 用語

| 用語 | 意味 | コード上の名前 |
|---|---|---|
| 入力 | 入力欄に打ち込まれた1行の文字列 | `input` |
| 区切り | 答えと答えの間に入れる文字（§2） | — |
| 答え | 入力を区切りで分けた1つずつ（§2） | `Answer` |
| 空欄 | 答えが1つもない入力 | `empty` |
| 答えのかな | 答えをひらがなに直したもの（§3）。判定に使う | `kana` |
| かなに直せない答え | ひらがなに直せない答え。理由を1つ持つ（§4） | `unconvertible`、`UnconvertibleReason` |
| ローマ字入力 | 各モードの設定「ローマ字入力を許可」。ON のときだけ、ローマ字をかなに直す | `romajiAllowed` |
| 問 | 一度に出題する札のまとまり。札流しでは1枚、複数枚では同時枚数ぶん（最後の問は残りの枚数） | — |
| 判定 | 問と、問の札ごとに、正解かどうかを決めること（§5） | `judge` |

## 2. 入力を答えに分ける

1. 入力を、区切りの文字で分ける。区切りは次の5つで、1行の中で混ぜてよい。
   - 半角のカンマ「,」、全角のカンマ「，」、読点「、」、半角の空白、全角の空白
2. 分けた1つずつの、前後の空白（タブなど、区切り以外の空白）を除く。
3. 空になったものは数えない。残ったものが答えで、入力した順に並ぶ。
4. 答えが1つもなければ、空欄とする。【要確認】§10 の 2

例：

| 入力 | 答え |
|---|---|
| 「む」 | む |
| 「 む 」 | む |
| 「ima,,naniwae,tiha,」 | ima、naniwae、tiha の3つ |
| 「む、す，め　ふ さ」 | む、す、め、ふ、さ の5つ |
| 「う か」 | う、か の2つ |
| 「ka ze wo」 | ka、ze、wo の3つ |
| 「」、「　 」、「、、」 | なし（空欄） |

答えの途中の空白は区切りになるので、1つの答えの中に空白は残らない。【変更】サンプルは、ローマ字の途中の空白を無視していた（取扱説明書 §1.3）。

## 3. 答えをひらがなに直す

答えを1つずつ、次の順に調べ、最初に当てはまったものを結果とする。答えどうしは関係しない。ローマ字入力の設定のほかに、結果を変えるものはない。

| 順 | 答え | 結果 |
|---|---|---|
| 1 | ひらがなと半角英字の両方を含む | かなに直せない（かなとローマ字の混在） |
| 2 | ひらがなを含む | 答えそのものが、答えのかな |
| 3 | 半角英字を含み、ローマ字入力が OFF | かなに直せない（ローマ字入力が許可されていない） |
| 4 | 半角英字を含み、ローマ字入力が ON | §3.1 で変換できれば、それが答えのかな。できなければ、かなに直せない（変換できないローマ字） |
| 5 | それ以外（ひらがなも半角英字も含まない） | かなに直せない（ひらがなでもローマ字でもない） |

- ひらがな：U+3041〜U+3096（ぁ〜ゖ）。半角英字：A〜Z、a〜z。
- 順 2 では、ひらがな以外の文字（カタカナ、数字など）が混ざっていても、そのまま答えのかなになる。正解の決まり字には一致しないので、不正解になる。例：「はなサ」。
- かなとローマ字の混在は、1つの答えの中だけで見る。答えごとに、かなとローマ字を変えてよい。例：「む、su」は、答えのかなが「む」「す」。

### 3.1 ローマ字の変換

- 大文字と小文字を区別しない。
- 母音（a・i・u・e・o）の後ろで区切り、区切った1つずつを、次の表で1文字のかなにする。表にないものが1つでもあれば、変換できない。

| つづり | a | i | u | e | o |
|---|---|---|---|---|---|
| 母音だけ | あ | い | う | え | お |
| k | か | き | く | け | こ |
| g | が | ぎ | ぐ | げ | ご |
| s | さ | し（si・shi） | す | せ | そ |
| z | ざ | じ（zi・ji） | ず | ぜ | ぞ |
| t | た | ち（ti・chi） | つ（tu・tsu） | て | と |
| d | だ | ぢ | づ | で | ど |
| n | な | に | ぬ | ね | の |
| h | は | ひ | ふ（hu・fu） | へ | ほ |
| b | ば | び | ぶ | べ | ぼ |
| p | ぱ | ぴ | ぷ | ぺ | ぽ |
| m | ま | み | む | め | も |
| y | や | い | ゆ | え | よ |
| r | ら | り | る | れ | ろ |
| w | わ | ゐ | う | ゑ | を |

- 「を」は wo、「は」は ha と、かなの表記どおりに入力する（仕様 01 §3）。例：kazewo は「かぜを」、imaha は「いまは」。
- 44番「おおこ」は ooko と入力する。ouko は「おうこ」になるので、正解にならない。
- yi・ye・wu は、い・え・う になる。wi・we・di・du は ゐ・ゑ・ぢ・づ になるが、これらの文字は決まり字に現れないので、正解にはならない。
- 撥音・促音・拗音は扱わない（決まり字に現れない。仕様 01 §3）。次のものは表にないので、変換できない：n・nn（ん）、子音を重ねたもの（っ）、kya・sha・cho などの拗音、ja・ju・jo、fa・fi など fu 以外の f で始まるもの、c・l・q・v・x で始まるもの、母音で終わらないもの、数字・記号・全角英字を含むもの。

## 4. かなに直せない理由

| 理由 | 答えの例 | コード上の名前 |
|---|---|---|
| かなとローマ字の混在 | うka | `mixed` |
| ローマ字入力が許可されていない | mu（ローマ字入力が OFF のとき） | `romaji-not-allowed` |
| 変換できないローマ字 | n、kka、kya、mu1 | `romaji-unconvertible` |
| ひらがなでもローマ字でもない | ム（カタカナ）、ｍｕ（全角英字）、無、1、！ | `not-kana-or-romaji` |

- 理由を分けるのは、表示する理由を入力に合わせるため（B-22）。サンプルは、混在以外をすべて「ローマ字表記が仕様外」としていたので、カタカナを入力しても、ローマ字を誤ったような理由が出ていた。
- 画面に表示する文言は、アプリ全体のメッセージの管理で決める（取扱説明書 §8.2）。この文書は、理由の区別だけを定める。

## 5. 判定

札流しの問（1枚）と、複数枚の問（1枚以上）で、同じ規則を使う。

- **正解の決まり字**：問が出た時点の候補集合で、仕様 01 §4.1 により求める。候補集合は、決まり字変化 OFF なら100首、ON なら「100首 − 既読」（仕様 01 §6.2）。同じ問の中では変えない（取扱説明書 §3.7）。例：「うか」と「うら」が同じ問に出たら、正解は「うか」と「うら」。
- **答えごと**：答えのかなが、問のどれかの札の決まり字と完全に一致すれば、その答えは合っている。かなに直せない答えは、合っていない。
- **問の正誤**：答えの数が問の札の枚数と同じで、どの札の決まり字もちょうど1回ずつ答えているときだけ、問は正解。答える順番は問わない。それ以外は不正解：答えの数が違う、同じ答えが2回ある、合っていない答えがある、など（取扱説明書 §3.5）。
- **札ごとの正誤**（2枚以上の問）：その札の決まり字が、答えのかなの中にあれば、その札は正解。問が不正解でも、札ごとには正解になりうる。決まり字一覧の各行の正誤に使う（取扱説明書 §3.10）。
- **札ごとの正誤**（1枚の問）：問の正誤と同じ。【要確認】§10 の 1
- 変化前の決まり字（長い方）、短すぎる答え、余計な文字のある答えは、合っていない。例：「うら」が既読のとき、「うか」の札に「うか」と答えると不正解。決まり字変化を追えていないため（取扱説明書 §2.5）。

例：5枚の問に、答えを6つ入れた。5つは5枚の札の決まり字で、残りの1つはかなに直せない答え。

- 6つとも、合っているかを調べる。
- 答えの数（6）が札の枚数（5）と違うので、問は不正解。
- 5枚の札は、どれも決まり字が答えの中にあるので、札ごとには正解。決まり字一覧には正解として表示する。

## 6. 各モードでの扱い

各モードの仕様は、次に従う。

- 空欄で Enter（または「答える」）を押しても、受け付けない。判定しない。答えずに先へ進むときは「スキップ」を使い、スキップとして記録する（取扱説明書 §8.1、B-25）。
- 答えが1つ以上あれば、Enter（または「答える」）で、その場で判定する（§5）。札流しも複数枚も同じ。かなに直せない答えも、答えの数に数える。
  - 【変更】サンプルの複数枚は、1枚ぶんずつ入力して Enter を押し、無効な入力は受け付けずに打ち直させていた（取扱説明書 §3.5）。
- 札流しの判定の表示には、かなに直せない理由も出す（取扱説明書 §2.5）。答えの数が違うことも、判定の結果から分かる。表示の文言は、メッセージの管理で決める。
- ローマ字入力の設定は、札流しと複数枚で別々にある（取扱説明書 §2.3、§3.3）。複数枚でも、設定どおりにローマ字をかなに直す（B-03）。

## 10. 確認してほしいこと

1. **1枚の問の札ごとの正誤**（§5）。2枚以上の問と同じ規則（その札の決まり字が答えの中にあれば正解）にすると、札流しで「む す」と答えたとき、判定は「不正解」なのに、決まり字一覧では「む」が正解になる。同じ札について、判定の表示と一覧が食い違う。
   - 提案：1枚の問では、札の正誤を問の正誤と同じにする。1枚の問は、問と札が同じものなので。
2. **区切りしかない入力**（§2）。「、、」や「 , 」は、答えが1つもないので空欄として扱い、受け付けない（判定しない）。
   - 提案：このとおり。何も入力していない場合と同じ扱いにする。
