# 仕様 02: 答えの入力と判定

札流しと札流し（複数枚）では、決まり字をキーボードで入力して答える。

- 札流し：答えを1つ入力する。入力の全体が答えで、決まり字と完全に一致したときだけ正解。
- 複数枚：問の札の枚数ぶんの答えを、1行に区切りの文字で分けて入力する。

この文書は、入力を答えにすること、答えをひらがなに直すこと（かな・ローマ字）、答えが正解かどうかの判定、受け付けない入力の扱いを定める。

スキップ、次の問へ進む操作などの進行と、判定の表示は、各モードの仕様で定める。正解の決まり字の求め方は、[仕様 01](01-karuta-rules.md) に従う。

根拠：

- 取扱説明書 §1.3（入力の規則。ユーザー確認済み）、§2.5（札流しの判定）、§3.5・§3.7・§3.8（複数枚の判定）、§8.1（空欄）
- 不具合 B-03・B-22・B-25 の本来の動き
- ユーザーの決定（2026-10-31。§12）
- 取扱説明書に書いていない細部は、サンプルを動かして確かめた（§10）

## 1. 用語

| 用語 | 意味 | コード上の名前 |
|---|---|---|
| 入力 | 入力欄に打ち込まれた1行の文字列 | `input` |
| 空欄 | 何も入力していないこと（長さ 0 の入力） | `empty` |
| 区切り | 複数枚で、答えと答えの間に入れる文字（§3） | — |
| 答え | 札流しでは入力の全体。複数枚では、入力を区切りで分けた1つずつ | `Answer` |
| 答えのかな | 答えをひらがなに直したもの（§4）。判定に使う | `kana` |
| かなに直せない答え | ひらがなに直せない答え。理由を1つ持つ（§5） | `unconvertible`、`UnconvertibleReason` |
| ローマ字入力 | 各モードの設定「ローマ字入力を許可」。ON のときだけ、ローマ字をかなに直す | `romajiAllowed` |
| 問 | 一度に出題する札のまとまり。札流しでは1枚、複数枚では同時枚数ぶん（最後の問は残りの枚数） | — |
| 問の札の枚数 | その問に実際に出ている札の枚数。複数枚の最後の問では、残りの枚数 | — |
| 判定 | 問と、問の札ごとに、正解かどうかを決めること（§6） | `judge` |

## 2. 札流しの答え

- 入力の全体が、そのまま1つの答えになる。前後の空白も、区切りの文字も、取り除かない。
- 答えを §4 でかなに直し、決まり字と完全に一致したときだけ正解（§6.1）。
- 前後や途中に空白や区切りの文字があれば、決まり字とは一致しないので、不正解になる。例：「 む」「む 」「む、」「う か」は、どれも不正解。
- 空欄は受け付けない（§7）。空白だけの入力は空欄ではないので、判定して不正解になる。

## 3. 複数枚の答え

1. 入力を、区切りの文字で分ける。区切りは次の5つで、1行の中で混ぜてよい。
   - 半角のカンマ「,」、全角のカンマ「，」、読点「、」、半角の空白、全角の空白
2. 分けた1つずつの、前後の空白（タブなど、区切り以外の空白）を除く。
3. 空になったものは数えない。残ったものが答えで、入力した順に並ぶ。行の先頭や末尾の区切り、続けて入れた区切りは、答えの数に影響しない。
4. 結果は、次のどれか。
   - 空欄：何も入力していない
   - 区切りだけ：入力はあるが、答えが1つもない
   - 答え：1つ以上

例：

| 入力 | 結果 |
|---|---|
| 「む」 | 答え：む |
| 「 む 」 | 答え：む |
| 「む、」 | 答え：む |
| 「ima,,naniwae,tiha,」 | 答え：ima、naniwae、tiha の3つ |
| 「む、す，め　ふ さ」 | 答え：む、す、め、ふ、さ の5つ |
| 「う か」 | 答え：う、か の2つ |
| 「ka ze wo」 | 答え：ka、ze、wo の3つ |
| 「」 | 空欄 |
| 「、、」、「　 」、「 , 」 | 区切りだけ |

答えの途中の空白は区切りになるので、1つの答えの中に空白は残らない。【変更】サンプルは、ローマ字の途中の空白を無視していた（取扱説明書 §1.3）。

最後の問が1枚だけのときも、同じ規則を使う。特別には扱わない（§7）。

## 4. 答えをひらがなに直す

札流しと複数枚で共通。答えを1つずつ、次の順に調べ、最初に当てはまったものを結果とする。答えどうしは関係しない。ローマ字入力の設定のほかに、結果を変えるものはない。

| 順 | 答え | 結果 |
|---|---|---|
| 1 | ひらがなと半角英字の両方を含む | かなに直せない（かなとローマ字の混在） |
| 2 | ひらがなを含む | 答えそのものが、答えのかな |
| 3 | 半角英字を含み、ローマ字入力が OFF | かなに直せない（ローマ字入力が許可されていない） |
| 4 | 半角英字を含み、ローマ字入力が ON | §4.1 で変換できれば、それが答えのかな。できなければ、かなに直せない（変換できないローマ字） |
| 5 | それ以外（ひらがなも半角英字も含まない） | かなに直せない（ひらがなでもローマ字でもない） |

- ひらがな：U+3041〜U+3096（ぁ〜ゖ）。半角英字：A〜Z、a〜z。
- 順 2 では、ひらがな以外の文字（空白、区切りの文字、カタカナ、数字など）が混ざっていても、そのまま答えのかなになる。正解の決まり字には一致しないので、不正解になる。例：「はなサ」、札流しの「む、」。
- かなとローマ字の混在は、1つの答えの中だけで見る。複数枚では、答えごとに、かなとローマ字を変えてよい。例：「む、su」は、答えのかなが「む」「す」。

### 4.1 ローマ字の変換

- 大文字と小文字を区別しない（取扱説明書 §1.3、確認済み）。
- 母音（a・i・u・e・o）の後ろで区切り、区切った1つずつを、次の表で1文字のかなにする。表にないものが1つでもあれば、変換できない。

| つづり | a | i | u | e | o |
|---|---|---|---|---|---|
| 母音だけ | あ | い | う | え | お |
| k | か | き | く | け | こ |
| g | が | ぎ | ぐ | げ | ご |
| s | さ | し（si・shi） | す | せ | そ |
| z | ざ | じ（zi・ji） | ず | ぜ | ぞ |
| t | た | ち（ti・chi） | つ（tu・tsu） | て | と |
| d | だ | ぢ | づ | で | ど |
| n | な | に | ぬ | ね | の |
| h | は | ひ | ふ（hu・fu） | へ | ほ |
| b | ば | び | ぶ | べ | ぼ |
| p | ぱ | ぴ | ぷ | ぺ | ぽ |
| m | ま | み | む | め | も |
| y | や | い | ゆ | え | よ |
| r | ら | り | る | れ | ろ |
| w | わ | ゐ | う | ゑ | を |

- 「を」は wo、「は」は ha と、かなの表記どおりに入力する（仕様 01 §3）。例：kazewo は「かぜを」、imaha は「いまは」。
- 44番「おおこ」は ooko と入力する。ouko は「おうこ」になるので、正解にならない。
- yi・ye・wu は、い・え・う になる。wi・we・di・du は ゐ・ゑ・ぢ・づ になるが、これらの文字は決まり字に現れないので、正解にはならない。
- 撥音・促音・拗音は扱わない（決まり字に現れない。仕様 01 §3）。次のものは表にないので、変換できない：n・nn（ん）、子音を重ねたもの（っ）、kya・sha・cho などの拗音、ja・ju・jo、fa・fi など fu 以外の f で始まるもの、c・l・q・v・x で始まるもの、母音で終わらないもの、空白・数字・記号・全角英字を含むもの。

## 5. かなに直せない理由

| 理由 | 答えの例 | コード上の名前 |
|---|---|---|
| かなとローマ字の混在 | うka | `mixed` |
| ローマ字入力が許可されていない | mu（ローマ字入力が OFF のとき） | `romaji-not-allowed` |
| 変換できないローマ字 | n、kka、kya、mu1、札流しの「 mu」 | `romaji-unconvertible` |
| ひらがなでもローマ字でもない | ム（カタカナ）、ｍｕ（全角英字）、無、1、！、札流しの空白だけの入力 | `not-kana-or-romaji` |

- 理由を分けるのは、表示する理由を入力に合わせるため（B-22）。サンプルは、混在以外をすべて「ローマ字表記が仕様外」としていたので、カタカナを入力しても、ローマ字を誤ったような理由が出ていた。
- 画面に表示する文言は、アプリ全体のメッセージの管理で決める（取扱説明書 §8.2）。この文書は、理由の区別だけを定める。

## 6. 判定

### 6.1 札流し

- 答えのかなが、正解の決まり字と完全に一致したときだけ正解。かなに直せない答えは不正解。
- 問は1枚なので、問の正誤と札の正誤は同じ。
- 変化前の決まり字（長い方）、短すぎる答え、余計な文字のある答えは、不正解。例：「うら」が既読のとき、「うか」の札に「うか」と答えると不正解。決まり字変化を追えていないため（取扱説明書 §2.5）。

### 6.2 複数枚

答えが1つ以上で、問の札の枚数を超えないときに判定する（超えるときは判定しない。§7）。

- **答えごと**：答えのかなが、問のどれかの札の決まり字と完全に一致すれば、その答えは合っている。かなに直せない答えは、合っていない。
- **問の正誤**：答えの数が問の札の枚数と同じで、どの札の決まり字もちょうど1回ずつ答えているときだけ、問は正解。答える順番は問わない。それ以外は不正解：答えが足りない、同じ答えが2回ある、合っていない答えがある、など（取扱説明書 §3.5）。
- **札ごとの正誤**：その札の決まり字が、答えのかなの中にあれば、その札は正解。問が不正解でも、札ごとには正解になりうる。決まり字一覧の各行の正誤に使う（取扱説明書 §3.10）。
- **答えが問の札の枚数より少ないとき**：ふつうに判定する。入れた答えはどれも有効で、答えのなかった札は不正解になる。問は不正解。例：「む」「す」の問に「む」だけを入れると、む は正解、す は不正解。
- 最後の問が1枚だけのときも、同じ規則を使う。答えは1つまでなので、問の正誤と札の正誤は同じになる。

例：5枚の問に、答えを5つ入れた。4つは4枚の札の決まり字で、残りの1つはかなに直せない答え。

- 問は不正解。
- 4枚の札は、決まり字が答えの中にあるので、札ごとには正解。決まり字一覧には正解として表示する。残りの1枚は不正解。

### 6.3 正解の決まり字

両モードで共通。

- 問が出た時点の候補集合で、仕様 01 §4.1 により求める。候補集合は、決まり字変化 OFF なら100首、ON なら「100首 − 既読」（仕様 01 §6.2）。
- 同じ問の中では変えない（取扱説明書 §3.7）。例：「うか」と「うら」が同じ問に出たら、正解は「うか」と「うら」。

## 7. 受け付けない入力

受け付けない入力では、判定しない。成績にも数えない。

| 入力 | 札流し | 複数枚 |
|---|---|---|
| 空欄 | 受け付けない（取扱説明書 §8.1、B-25） | 受け付けない（同左） |
| 区切りだけ | ― （区切りを特別扱いしないので、判定して不正解になる。§2） | 受け付けない。その旨をメッセージで伝え、入力欄を空にする |
| 答えが、問の札の枚数より多い | ― （答えは常に1つ） | 受け付けない。答え全体を無効とし、その旨をメッセージで伝え、入力欄を空にする 【要確認】§11 |

- 上の表のほかは、Enter（または「答える」）で、その場で判定する（§6）。
- 答えずに先へ進むときは「スキップ」を使い、スキップとして記録する（取扱説明書 §8.1）。
- 札流しの判定の表示には、かなに直せない理由も出す（取扱説明書 §2.5）。
- メッセージの文言は、メッセージの管理で決める。
- 【変更】サンプルの複数枚は、1枚ぶんずつ入力して Enter を押し、無効な入力は受け付けずに打ち直させていた（取扱説明書 §3.5）。最後の問が1枚だけのときは、空欄などの無効な入力でもその場で判定していた（取扱説明書 §3.8）。
- ローマ字入力の設定は、札流しと複数枚で別々にある（取扱説明書 §2.3、§3.3）。複数枚でも、設定どおりにローマ字をかなに直す（B-03）。

### 8.3 回帰テスト

B-03・B-22・B-25 の「直したら確かめること」のうち、答えをかなに直す部分は、§8.1 のベクタで確かめる。画面での動き（判定が出ない、メッセージが出て入力欄が空になる、など）は、各モードの受け入れテストで確かめる。

## 9. 現行サンプルとの対応

| 項目 | 現行サンプル | 新しい版 |
|---|---|---|
| 答えの入れ方 | 札流しは1つ。複数枚は、1枚ぶんずつ入力して Enter | 札流しは1つで、入力の全体が答え（§2）。複数枚は、1行に区切って入力する（§3） |
| 空白 | 前後の空白を除く。ローマ字では途中の空白も無視する | 札流しは除かない（空白があれば不正解）。複数枚では区切りになり、分けた答えの前後の空白は除く |
| ローマ字の変換 | 札流しと複数枚で、別々の実装。複数枚の実装は ん・っ・きゃ なども変換するが、設定が読み込まれないので使われない（B-03） | 1つの規則（§4.1）を両方で使う。札流しの規則（取扱説明書 §1.3、確認済み）と同じ |
| 直せない入力の理由 | 混在と「ローマ字表記が仕様外」の2種類。カタカナ・全角英字・漢字・空欄も「仕様外」（B-22、B-25） | 4種類（§5）。空欄は理由ではなく、受け付けない |
| 空欄 | 札流しと、複数枚の1枚だけの問では、不正解として判定する（B-25） | 受け付けない（§7） |
| 複数枚の無効な入力 | 受け付けずに打ち直させる | 答えの数に数え、合っていない答えとする。答えが多すぎる入力と区切りだけの入力は、メッセージを出して入力欄を空にする |
| 複数枚の最後の1枚の問 | 1回の入力ですぐ判定する。空欄でも判定する | ほかの問と同じ規則（§3、§7） |
| 複数枚のローマ字入力 | 設定に関わらず、受け付けない（B-03） | 設定どおり |
| 複数枚の札ごとの正誤 | その札の決まり字が答えの中にあれば正解（コードで確認。画面には出ない） | 同じ（§6.2） |

## 11. 確認してほしいこと

1. **「答えが多すぎる」の比べる相手**（§7）。複数枚の最後の問は、同時枚数より少ない枚数で出る（例：同時枚数 5、最後の問は 1枚）。このとき、答えの数は、設定の同時枚数ではなく、**その問に実際に出ている札の枚数** と比べる。最後の1枚の問では、答えが2つ以上なら受け付けない。
   - 提案：このとおり。最後の問も「特別扱いせず、2枚以上の問と同じ」にするため。設定の同時枚数と比べると、最後の1枚の問で答えを5つまで入れられ、問は不正解なのに札は正解、という食い違いが出る。
